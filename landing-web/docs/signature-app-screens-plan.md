# 사인·실제 앱 화면 작업 계획

- 범위: 랜딩 체험 사인 단계 추가, 히어로·사용법 실제 앱 캡처 전환. 본 워크트리의 client/admin/backend와 정책 문서는 수정하지 않는다.
- 보존: 히어로 제목·설치 링크·체험 CTA, 카메라 좌표/크롭, 다른 작가 사인, 재촬영. 기존 테스트 17개 통과를 먼저 확인하고 히어로 문구 회귀 테스트를 추가한다.
- 삭제 순서: 실제 캡처 확보 후 사용법 파일 존재 분기·mock 컴포넌트/CSS 삭제; 풍경 히어로 프레임 코드 삭제. 캡처 누락을 mock으로 숨기지 않는다.
- 사인: iOS 원본 정규화 획·평활 곡선·PNG 배치에 순수 로직 테스트를 추가한다. 체험 메모리에만 보관하고 재촬영 시 유지한다.
- 검증: lint/typecheck/test/build, 1280/390 브라우저에서 히어로·5장·사인 전체 흐름·포인터 입력·페이지 가로 넘침 검사.
- 정책 연결: 설치 status --check가 `자동 진입 지침이 수정되었습니다: AGENTS.md`로 실패했다. 진입 지침을 덮어쓰거나 설치 성공·최신 정책 동기화 성공으로 표시하지 않는다. 저장소의 사인 규칙은 읽기 전용 참조이며 실제 회원가입/등록/API 동작 변경은 없다.
- 최종 시각 검수에서 기존 `display-*` 파일명에 대한 Next 이미지 캐시가 예전 화면을 재사용한 것을 발견했다. 공통 캡처 버전을 이미지 URL에 넣고 `images.localPatterns`에서 그 버전만 허용한다. 새 캡처로 교체할 때는 버전도 갱신한다. 이것은 예시 화면 fallback이 아니라 동일 파일명의 캐시 키 경계 수정이다.
