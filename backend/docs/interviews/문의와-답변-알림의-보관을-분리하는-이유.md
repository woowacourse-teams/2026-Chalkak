# 문의와 답변 알림의 보관을 분리하는 이유

2026-11-04 · [#905 고객센터 관리자 답변과 사용자 알림 연동](https://github.com/woowacourse-teams/2026-Chalkak/issues/905)

관리자는 삭제된 문의의 질문과 답변도 볼 수 있어야 한다. 두 원문은 `feedbacks` 한 행에 보존한다. 알림함에는 고정 안내와 문의 ID를 가진 별도 행을 저장하므로, 그 행을 지워도 원문을 잃지 않는다.

처음에는 문의 삭제 시 알림 행에 삭제 시각을 기록하고 정리 스케줄러가 나중에 행을 지우는 방식이었다. 문의의 기록 보존과 알림의 데이터 정리가 서로 다른 목적이라는 점을 확인한 뒤, 문의를 소프트 딜리트할 때 연결된 답변 알림은 같은 트랜잭션에서 DB에서 삭제하기로 했다. 발행 대기 조회와 발송 직전 조회는 삭제된 알림 행을 찾지 못하므로 이후 처리를 건너뛴다. 이미 시작된 외부 전송은 회수할 수 없다.

문의가 남아 있으면 알림은 기존 30일 보관 정책을 따른다. 알림이 만료되어 정리된 뒤에도 문의 상세에서 답변을 읽을 수 있다. 적용 규칙은 [고객센터 답변 알림](../../../docs/business-rules/rules/notification.md#notification-018-고객센터-답변-알림)에 정리했다.

PostgreSQL 통합 테스트에서 사용자·관리자 삭제 후 답변 알림 행이 사라지고 관리자 상세에 원문이 남는 것을 확인했다. 30일을 넘긴 알림은 정리 스케줄러가 삭제했으며, 문의를 삭제하지 않은 사용자는 상세에서 답변을 계속 읽을 수 있었다.
