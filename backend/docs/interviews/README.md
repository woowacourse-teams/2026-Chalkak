# 선택에 이른 고민

기획·인터뷰·개발 중 어떤 질문과 비교를 거쳐 선택했는지 공유한다. 현재 서비스 정책은 [비즈니스 규칙](../../../docs/business-rules/README.md)을 기준으로 확인한다.

| 고민 | 소개 | 상태 |
| --- | --- | --- |
| [캘린더에 기록이 있는 달을 알려주는 방법](캘린더-기록-연월-조회-방식.md) | 이전 달 존재 여부 대신 현재 조회 가능한 게시물의 연월 목록을 제공한다. | 방향 합의 |
| [브랜치가 다른 클라이언트와 비즈니스 규칙을 공유하는 방법](브랜치가-다른-클라이언트와-비즈니스-규칙-공유.md) | 병합 후 공통 하네스를 자동 게시하고 Android의 읽기 전용 사용·정책 변경 요청을 연결한다. | 방향 합의 |

`논의 중`은 미결정이 남은 기록, `방향 합의`는 선택을 합의한 기록, `구현·검증 완료`는 해당 주제의 구현과 필요한 검증을 확인한 기록이다. 마지막 상태도 모든 위험의 해소나 운영 효과의 입증을 뜻하지 않는다.

새 주제는 한국어 파일명으로 추가하고 같은 고민은 기존 문서를 갱신한다. 제목·분량은 내용에 맞춰 정하며 세부 작성 기준은 [고민 기록 스킬](../../.agents/skills/decision-notes/SKILL.md)을 따른다.
