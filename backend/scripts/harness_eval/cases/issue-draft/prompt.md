앞서 기획한 백엔드 로컬 실행 안내 작업의 이슈 초안 작성해줘.

합의한 내용은 다음과 같아.

- 신규 팀원이 실행 도구와 명령을 따로 물어봐야 해서 `backend/README.md`의 로컬 실행 안내를 보완한다.
- 필요한 JDK 버전은 25이며, `backend/`에서 `./gradlew bootRun`으로 실행한다는 내용을 추가한다.
- 완료 기준은 README에서 JDK 버전, 명령을 실행할 위치와 실행 명령을 모두 확인할 수 있는 것이다.
- 구현 코드와 빌드 설정 변경은 이번 범위에서 제외한다. 아직 문서를 수정하거나 검증하지는 않았다.

앞서 확인한 저장소의 작업 유형 라벨은 `feat`, `fix`, `docs`, `chore`이고, 백엔드 라벨은 `Server`야. 등록에 사용할 인증 계정과 내가 원하는 작성자 계정은 모두 `fixture-author`로 확인했고, 통합 브랜치는 `be/develop`, 이 문서 작업의 브랜치 유형은 `fix`로 합의했어. 이 작업은 아직 이슈 번호가 없어.
