메인 이슈 #900은 사용자 피드백 접수와 관리자 확인 기능이야. 인터뷰 결과는 승인했고 아래가 합의 내용이야. 아직 이슈 등록은 하지 말고 서브 이슈 분할표와 등록할 본문을 보여줘.
- 로그인 사용자는 내용 1~1000자로 피드백을 접수한다. DB 저장 실패는 성공 응답으로 처리하지 않는다.
- 접수된 피드백을 Slack에 알린다. Slack 실패가 이미 성공한 접수를 취소하지 않는다.
- 관리자만 피드백 목록을 페이지 단위로 조회하고 개별 상세를 확인한다.
- 관리자는 내용 키워드로 목록을 검색할 수 있다.
- 삭제·수정·첨부파일은 제외한다. 권한, 입력 경계, 실패 동작과 회귀 테스트까지 각 동작의 완료 조건이야.
실제 서비스 코드는 이 자료에 없으니 파일·구현 상태를 지어내지 마. 저장소 team/fixture, 통합 브랜치 be/develop, 계정 fixture-author, 존재 라벨 Server·feat·fix·refactor로 확인됐어. 개발은 분할안을 보고 정할게.
