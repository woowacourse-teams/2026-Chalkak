# <화면 이름> 화면

`client-record`가 화면 확인 방법을 남길 때 이 형식으로 `references/<화면-영어-이름>.md`를 만든다.
iOS도 같은 형식을 `ios-simulator/references/`에 둔다.

```markdown
# 작가 프로필 화면

가는 길: 피드 → 사진 탭 → 작가 이름 탭
딥링크: 없음

확인 조건
- 긴 소개: 소개가 4줄 이상인 테스트 작가 프로필
- 빈 소개: 소개를 지운 테스트 작가 프로필

주의
- 사진은 서버에서 늦게 와서 전·후 비교 때 사진 영역을 --ignore로 뺀다
```

테스트 계정 정보(이메일, 비밀번호)는 적지 않는다. 레포가 공개다.
