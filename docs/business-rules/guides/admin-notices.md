# 관리자 공지 연동 안내

## 현재 제공 범위

#592에서 공지 등록 API를 구현한다. 공지 조회는 같은 이슈의 후속 변경, 수정·삭제는 #593, 예약 시각의 알림함 생성은 #594, 실제 푸시 발송은 #595에서 추가한다. 실제 배포와 관리자 클라이언트 연동은 아직 확인하지 않았다. 정책은 [알림 규칙](../rules/notification.md)의 NOTIFICATION-012를 따른다.

## 공지 등록

`POST /api/v1/admin/notices`

관리자 액세스 토큰을 `Authorization: Bearer <adminAccessToken>`으로 전달한다. 일반 회원 토큰은 사용할 수 없다.

```json
{
  "title": "서비스 점검 안내",
  "body": "10월 20일 02:00부터 04:00까지 서비스 점검이 진행됩니다.",
  "scheduledAt": "2026-10-19T09:00:00Z"
}
```

- `title`은 필수이며 앞뒤 공백을 제거한 뒤 1~50자다. 이모지 등은 UTF-16 길이가 아니라 문자 하나로 센다.
- `body`는 필수이며 앞뒤 공백을 제거한 뒤 1~500자다.
- `scheduledAt`은 필수이며 시간대가 포함된 ISO-8601 시각(UTC Instant)이다. 즉시 발송하려면 현재 시각을 보낸다. 요청 처리 시각보다 5분 넘게 과거인 값은 거절하고, 정확히 5분 전까지는 허용한다. 미래 시각에는 상한이 없다.
- 제목·본문에 이미지 URL이나 토큰 형식 문자열처럼 감사 로그가 민감 정보로 판정하는 값이 있으면 거절한다.
- 요청은 공지만 저장한다. 등록 요청 자체는 푸시를 보내지 않는다. 처리 관리자와 등록한 제목·본문·예약 시각을 감사 로그에 남기며, 감사 기록이 실패하면 공지도 저장하지 않는다.

성공은 `201`이며 저장된 공지를 반환한다. `title`·`body`는 앞뒤 공백을 제거한 값이다. 모든 시각은 UTC Instant다.

```json
{
  "noticeId": "019a0000-0000-7000-8000-000000000592",
  "title": "서비스 점검 안내",
  "body": "10월 20일 02:00부터 04:00까지 서비스 점검이 진행됩니다.",
  "scheduledAt": "2026-10-19T09:00:00Z",
  "createdAt": "2026-10-12T09:00:00Z",
  "updatedAt": "2026-10-12T09:00:00Z"
}
```

| 상태 | 오류 코드 | 의미 |
| --- | --- | --- |
| 400 | BUSINESS_ERROR | 필수 값 누락·공백, 제목·본문 길이 초과, 5분 넘게 과거인 예약 시각, 민감 정보 포함 |
| 401 | UNAUTHORIZED | 관리자 액세스 토큰이 없거나 유효하지 않음 |
| 403 | FORBIDDEN | 관리자 권한 없음 |

## 운영 주의

- 공지는 전용 수신 설정 없이 전체 회원에게 보낸다. 수신 거부 수단이 없으므로 광고성 정보를 넣지 않는다.
- 공지별 발송 결과는 관리자 API로 제공하지 않는다. 발송 단계가 구현되면 공지 ID로 CloudWatch Logs Insights에서 조회한다.
