# 주제 규칙

## TOPIC-001 주제 구성

- 규칙: 주제는 제목, 주제 날짜, 참여 시작 시각, 참여 종료 시각을 가진다. 제목은 앞뒤 공백을 제거한 뒤 비어 있지 않아야 하며 최대 255자다.
- 적용 범위: 주제 생성과 수정
- 예외: 없음
- 결정 기록: 없음

## TOPIC-002 주제 날짜

- 규칙: 주제 날짜는 참여 시작 시각의 KST 날짜와 같아야 한다. 삭제되지 않은 주제는 날짜마다 하나만 존재할 수 있다.
- 적용 범위: 주제 생성과 수정, 동시 생성
- 예외: 논리 삭제된 주제의 날짜는 새 주제에 다시 사용할 수 있다.
- 결정 기록: 없음

## TOPIC-003 참여 기간과 상태

- 규칙: 참여 종료 시각은 시작 시각보다 늦어야 한다. 시작 전은 `BEFORE_OPEN`, 시작 시각 이상 종료 시각 미만은 `OPEN`, 종료 시각 이상은 `CLOSED`다.
- 적용 범위: 주제 상태 표시, 게시물 작성 가능 여부
- 예외: 참여 기간을 KST 00:00 시작 또는 정확히 24시간으로 제한하지 않는다.
- 결정 기록: 없음

## TOPIC-004 관리자 변경

- 규칙: 관리자는 아직 `BEFORE_OPEN`인 주제만 생성·수정·삭제할 수 있다. 삭제는 논리 삭제로 처리한다.
- 적용 범위: 관리자 주제 관리
- 예외: 수정 값이 기존 값과 모두 같으면 변경 요청을 거절한다.
- 결정 기록: 없음

## TOPIC-005 사용자 조회

- 규칙: 사용자는 KST 기준 오늘 또는 과거 날짜의 삭제되지 않은 주제를 날짜로 조회할 수 있다.
- 적용 범위: 사용자 주제 조회
- 예외: 미래 날짜는 주제 존재 여부와 관계없이 조회할 수 없다.
- 결정 기록: 없음
