# 알림함 규칙

## NOTIFICATION-001 검수 결과 알림 생성

- 규칙: 관리자가 게시물을 승인하거나 반려하면 작성자의 알림함에 해당 검수 결과를 한 건 저장한다. 검수 상태 변경·관리자 감사 로그·알림 저장은 하나의 트랜잭션으로 처리한다. 같은 회원에게 같은 검수 사건의 알림을 중복 저장하지 않는다.
- 적용 범위: 관리자 게시물 검수 확정, 승인·반려 알림함 기록
- 예외: 검수가 실패하거나 트랜잭션이 롤백되면 알림도 남지 않는다. 이번 규칙은 검수 결과 알림함 기록에 적용하며 주제 알림과 푸시 발송은 포함하지 않는다.
- 결정 기록: [검수 결과 알림함 도입과 보관 기준](../decisions/2026-09-29-notification-inbox.md)

## NOTIFICATION-002 본인 알림 조회

- 규칙: 탈퇴하지 않은 회원은 본인의 알림만 최신순으로 조회한다. 목록에는 게시물 사진의 썸네일 URL과 읽은 시각을, 상세에는 원본 사진 URL과 반려 사유를 제공한다. 미읽음 알림이 하나라도 있는지도 조회할 수 있다.
- 적용 범위: 알림 목록·상세·미읽음 상태 조회
- 예외: 정지 회원도 본인의 알림을 조회할 수 있다. 다른 회원의 알림 상세는 찾을 수 없는 것으로 처리하며 탈퇴 회원의 인증된 알림함 접근은 차단한다. 반려 사유는 승인 알림에는 없다.
- 결정 기록: [검수 결과 알림함 도입과 보관 기준](../decisions/2026-09-29-notification-inbox.md)

## NOTIFICATION-003 읽음 상태

- 규칙: 회원은 본인의 알림 한 건 또는 본인의 미읽음 알림 전체를 읽음 처리할 수 있다. 이미 읽은 알림을 다시 처리해도 최초 읽은 시각을 유지한다.
- 적용 범위: 단건 읽음, 전체 읽음, 미읽음 상태
- 예외: 다른 회원의 알림은 단건 읽음 처리할 수 없다. 알림을 조회하는 것만으로는 읽음 처리하지 않는다.
- 결정 기록: [검수 결과 알림함 도입과 보관 기준](../decisions/2026-09-29-notification-inbox.md)

## NOTIFICATION-004 알림함 보관과 삭제

- 규칙: 일반 회원의 알림은 생성 시각부터 60일이 지난 뒤 정리한다. 탈퇴 회원의 남아 있는 알림은 생성 시각과 관계없이 탈퇴 시각부터 30일이 지난 뒤 정리한다.
- 적용 범위: 알림함 데이터의 주기적 삭제
- 예외: 탈퇴 요청 시 알림을 즉시 지우지 않는다. 두 기간의 정확한 경계 시각에는 보관하고, 경계 시각이 지난 알림을 다음 정리 실행 때 삭제한다. 이미 삭제된 알림을 탈퇴 때문에 복원하지 않는다.
- 결정 기록: [검수 결과 알림함 도입과 보관 기준](../decisions/2026-09-29-notification-inbox.md)
