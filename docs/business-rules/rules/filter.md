# 필터 규칙

## FILTER-001 초안 작성과 삭제

- 규칙: 이용 가능한 `ARTIST` 회원은 빈 `DRAFT` 필터를 만들 수 있으며, 수정과 삭제는 본인의 `DRAFT` 필터만 가능하다. 삭제 시 삭제 시각을 기록하고 목록과 상세에서 제외한다.
- 적용 범위: `POST /api/v1/filters`, `PATCH /api/v1/filters/{filterId}`, `DELETE /api/v1/filters/{filterId}`
- 예외: 같은 작가가 이미 삭제한 초안을 다시 삭제하면 처음 삭제 시각을 보존하고 `204`를 반환한다. 수정에서 생략하거나 `null`로 보낸 항목은 유지한다. 이름·설명에 빈 문자열이나 공백을 보내면 값을 지운다. 앞뒤 공백을 뺀 이름은 최대 30자, 설명은 최대 500자이며 Unicode 코드 포인트로 센다. NUL 문자(`U+0000`)를 포함하거나 수정할 항목이 없으면 `400`으로 거절한다.
- 결정 기록: [필터 초안과 소개 사진](../decisions/2026-11-12-filter-drafts.md)

## FILTER-002 소개 사진 연결

- 규칙: 초안 수정에 `uploadIds`를 보내면 본인 업로드 ID 1~5개를 요청 순서대로 연결해 목록을 교체한다. 한 요청에서 동일한 업로드 ID를 중복해 보낼 수 없다. 새로 연결할 사진에는 [POST-004](post.md#post-004-사진-업로드)의 소유권, 유효 기간과 일회 사용 규칙이 적용된다.
- 적용 범위: 필터 초안의 소개 사진 연결과 교체
- 예외: `ISSUED` 상태의 미사용 업로드도 새로 연결할 수 있다. `REJECTED` 상태는 새로 연결할 수 없다. 같은 초안에 연결된 사진의 순서를 바꿀 수 있다. 사진을 목록에서 빼거나 초안을 삭제해도 이미 사용한 업로드 ID는 다시 연결할 수 없다. 새 연결 중 오류가 발생하면 해당 요청의 초안 수정 전체를 되돌린다.
- 결정 기록: [필터 초안과 소개 사진](../decisions/2026-11-12-filter-drafts.md)

## FILTER-003 목록과 상세 조회

- 규칙: 로그인한 회원은 작가 페이지와 필터 상세에서 `PUBLIC` 필터를 조회할 수 있다. 작성자 본인에게는 `DRAFT`, `PRIVATE`도 표시한다. 삭제된 필터와 탈퇴한 작성자의 필터는 목록과 상세에서 제외한다.
- 적용 범위: `GET /api/v1/users/{userId}/filters`, `GET /api/v1/filters/{filterId}`
- 예외: 이용 정지된 회원도 조회할 수 있다. 작성자 본인의 상세에는 연결한 소개 사진의 처리 상태를 표시하며, 다른 회원의 상세에는 `READY` 사진만 표시한다. 조회 권한이 없는 상세는 `404`를 반환한다.
- 결정 기록: [필터 초안과 소개 사진](../decisions/2026-11-12-filter-drafts.md)
