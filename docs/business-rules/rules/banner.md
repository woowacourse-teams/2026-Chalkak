# 배너 규칙

## BANNER-001 등록 정보와 공개 대상

- 규칙: 관리자는 외부에 배포한 웹페이지의 제목(`title`), 부제목(`subtitle`), 웹뷰 URL(`webViewUrl`), 썸네일 URL(`thumbnailUrl`)을 등록한다. 네 항목은 모두 필수이며 등록 즉시 공개 대상이다.
- 적용 범위: 관리자 배너 등록
- 예외: 현재 관리자 등록·목록 조회·삭제 API를 제공하며 앱 공개 조회는 후속 작업이다. 웹페이지 배포와 이미지 업로드는 관리자가 별도로 수행하며 서버는 입력받은 주소의 콘텐츠를 가져오거나 검사하지 않는다.
- 결정 기록: [배너 등록과 URL 중복 판정](../decisions/2026-10-19-banner-registration.md)

## BANNER-002 입력 경계

- 규칙: 네 항목은 앞뒤 공백(일반 공백과 U+2003 등 유니코드 공백)을 제거한 값으로 검증·저장한다. 제목은 1~50자, 부제목은 1~100자이고, 두 URL은 각각 최대 2,000자의 호스트가 있는 HTTPS 절대 주소여야 한다. URL의 포트는 생략할 수 있으며 명시된 포트가 65535를 초과하면 거절한다. 길이는 Unicode code point 기준이다.
- 적용 범위: 관리자 배너 등록
- 예외: 빈 값이나 공백만 있는 값, 길이 초과, URL 형식·포트 범위 오류는 `400 / BUSINESS_ERROR`로 거절하며 URL 오류 메시지는 웹뷰 URL과 썸네일 URL을 구분한다. Vercel 이외의 HTTPS 도메인도 허용한다.
- 결정 기록: [배너 등록과 URL 중복 판정](../decisions/2026-10-19-banner-registration.md)

## BANNER-003 웹뷰 URL 중복

- 규칙: 동일한 웹뷰 URL의 미삭제 배너를 중복 등록할 수 없다. 앞뒤 공백 제거 후 전체 문자열이 같은 경우만 중복으로 판단하며, 쿼리와 프래그먼트를 제거하거나 주소를 재작성하지 않는다. 동시 요청에도 하나만 등록되고 감사 로그도 한 건만 남는다.
- 적용 범위: 관리자 배너 등록
- 예외: 중복은 `400 / BUSINESS_ERROR`로 거절한다. 같은 주소를 가리키더라도 전체 문자열이 다르면 별도 주소로 취급한다. 논리 삭제한 배너와 같은 URL은 새 ID로 재등록할 수 있다.
- 결정 기록: [배너 등록과 URL 중복 판정](../decisions/2026-10-19-banner-registration.md), [배너 논리 삭제와 재등록](../decisions/2026-10-19-banner-deletion.md)

## BANNER-004 관리자 목록 조회

- 규칙: 인증된 관리자는 `GET /api/v1/admin/banners`로 미삭제 배너만 조회한다. 등록 시각 내림차순이며 시각이 같으면 ID 내림차순으로 정렬한다. 페이지 번호는 1부터 시작하고 기본값은 1, 페이지 크기 기본값은 20이며 1~100개를 허용한다.
- 적용 범위: 관리자 배너 목록 조회
- 예외: 배너가 없거나 페이지 범위를 벗어나면 빈 목록과 `hasNext=false`를 반환한다. 응답은 `currentPage`, `pageSize`, `hasNext`, `banners`이며 각 배너는 ID·제목·부제목·웹뷰 URL·썸네일 URL·생성 시각을 담는다. 잘못된 페이지·크기 또는 offset(`(page - 1) × pageSize`)이 2,147,483,647을 초과하면 `400 / BUSINESS_ERROR`로 거절한다. 일반·정지·탈퇴 회원은 접근할 수 없다. 앱 공개 조회는 후속 기능이다.
- 결정 기록: [관리자 배너 목록 조회](../decisions/2026-10-19-admin-banner-list.md), [배너 논리 삭제와 재등록](../decisions/2026-10-19-banner-deletion.md)

## BANNER-005 관리자 삭제

- 규칙: 인증된 관리자는 요청 본문 없이 `DELETE /api/v1/admin/banners/{bannerId}`로 배너를 논리 삭제한다. 삭제 사유는 입력받거나 기록하지 않는다. 배너에는 최초 삭제 시각을 저장하고 관리자·대상·행위·변경 전후 상태·처리 시각·요청 식별자를 감사 로그에 기록한다. 삭제된 배너는 목록에서 제외되며 같은 URL로 새 배너를 등록할 수 있다.
- 적용 범위: 관리자 배너 삭제·목록·재등록
- 예외: 삭제 성공과 재삭제는 `204`다. 반복·동시 삭제는 최초 삭제 시각과 감사 한 건을 유지한다. 존재하지 않는 배너는 `404 / BUSINESS_ERROR`, 잘못된 UUID는 `400 / BUSINESS_ERROR`다. 일반·정지·탈퇴 회원은 접근할 수 없다. 감사 실패 시 삭제를 롤백한다. 외부 웹페이지·썸네일 파일은 삭제하지 않는다.
- 결정 기록: [배너 논리 삭제와 재등록](../decisions/2026-10-19-banner-deletion.md)
