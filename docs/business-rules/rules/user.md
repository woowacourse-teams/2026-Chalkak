# 회원 규칙

## USER-001 가입과 로그인

- 규칙: 소셜 계정 인증으로 회원을 식별한다. 가입 이력이 없는 소셜 계정은 회원가입이 필요하며, 사인 원본과 썸네일 처리가 완료되어야 가입할 수 있다. 가입한 회원의 초기 상태는 `ACTIVE`다.
- 적용 범위: 소셜 로그인, 회원가입
- 예외: 이미 가입한 정상 회원의 유효한 가입 완료 요청은 기존 회원으로 처리한다. 사인 이미지 조건과 처리 정책은 [사인 규칙](sign.md)을 따른다.
- 결정 기록: 없음

## USER-002 이용 정지

- 규칙: 이용이 정지된 `BANNED` 회원은 회원가입, 게시물 업로드·작성, 사인 업로드·교체, 좋아요 등록, AI 리뷰 요청, 작가 신청을 할 수 없다. 탈퇴하지 않은 정지 회원은 소셜 로그인으로 인증할 수 있다.
- 적용 범위: 로그인, 회원가입, 인증된 회원의 서비스 이용
- 예외: 인증된 정지 회원은 조회(본인 AI 리뷰 결과 포함), 허용된 본인 게시물 삭제, 기존 좋아요 취소, 회원 탈퇴, 피드백 제출을 할 수 있다. 피드백 제출 조건은 [피드백 규칙](feedback.md)을 따른다. 정지 상태로 탈퇴한 회원의 로그인과 재가입 차단은 USER-005를 따른다. 각 기능의 대상·상태 조건은 해당 도메인 규칙을 따른다. 정지·해제 절차는 [관리자 규칙](admin.md)을 따른다.
- 결정 기록: [정지 회원의 소셜 로그인 허용](../decisions/2026-09-03-banned-user-login.md), [피드백 수집 도입](../decisions/2026-09-16-feedback-collection.md), [AI 리뷰 요청·조회 도입](../decisions/2026-10-20-ai-review.md)

## USER-003 회원 탈퇴

- 규칙: 탈퇴하지 않은 회원은 본인 계정으로 인증하여 탈퇴할 수 있다. 탈퇴 시점을 기록하고 이후 탈퇴하지 않은 회원을 요구하는 조회·변경 대상에서 제외한다.
- 적용 범위: 회원 탈퇴, 탈퇴 후 회원 조회와 변경
- 예외: 정지된 회원도 탈퇴할 수 있다. 이미 탈퇴한 회원의 재탈퇴 요청은 거절한다.
- 결정 기록: 없음

## USER-004 탈퇴 시 회원 정보 처리

- 규칙: 탈퇴 시 회원 레코드는 논리 삭제한다. 이메일과 사인 원본 참조를 대체 값으로 바꾸고, 사인 썸네일 참조와 진행 중인 사인 처리 정보를 제거한다. 모든 로그인 RT를 폐기하고 해당 회원의 푸시 기기를 비활성화하며 FCM 토큰 원문과 해시를 즉시 제거한다. 탈퇴 시 본인 게시물(삭제된 게시물 포함)의 인스타그램 게시 동의를 철회하고 인스타그램 ID를 지우며 철회 시각을 탈퇴 시각으로 기록한다. 동의하지 않은 게시물은 바꾸지 않는다. 탈퇴와 겹친 게시물 작성·수정은 탈퇴 전에 처리되어 철회 대상이 되거나 탈퇴 뒤에 거부되므로 탈퇴한 회원의 게시물에 동의가 남지 않는다. 이 DB 변경은 하나의 트랜잭션에서 처리한다.
- 적용 범위: 탈퇴 시 회원 데이터 처리
- 예외: 회원 레코드 전체와 실제 사인 이미지 파일을 탈퇴 요청에서 물리 삭제하지는 않는다. 회원 레코드와 사인 파일의 보관 기간이나 일괄 영구 삭제 시점은 정해져 있지 않다. 푸시 기기 연결 해제는 [NOTIFICATION-005](notification.md#notification-005-현재-로그인-기기-등록해제), 알림함 보관 기간은 NOTIFICATION-004를 따른다.
- 결정 기록: [로그인별 푸시 기기 등록](../decisions/2026-09-30-push-device-registration.md), [인스타그램 게시 동의](../decisions/2026-11-03-instagram-upload-consent.md#탈퇴와-동의-철회)

## USER-005 탈퇴 후 재가입

- 규칙: 정상 회원이 탈퇴하면 소셜 계정 연결을 삭제하므로 같은 소셜 계정으로 새로 가입할 수 있다. 재가입은 새 회원으로 처리한다.
- 적용 범위: 탈퇴 시 소셜 계정 처리, 재가입
- 예외: 정지된 회원은 탈퇴해도 소셜 계정 식별 정보와 정지 상태를 유지하여 같은 소셜 계정의 로그인과 재가입을 차단한다.
- 결정 기록: 없음

## USER-006 탈퇴 후 게시물과 좋아요

- 규칙: 탈퇴한 작성자의 게시물은 공개 대상에서 제외한다. 탈퇴 요청은 기존 게시물·사진·좋아요 레코드를 일괄 삭제하지 않는다.
- 적용 범위: 회원 탈퇴, 게시물 공개 범위, 기존 데이터 처리
- 예외: 회원 탈퇴와 게시물 삭제는 별도 처리다. 게시물 삭제 시의 사진·좋아요 처리는 [게시물 규칙](post.md)을 따른다. 탈퇴만으로 해당 회원이 남긴 좋아요가 일괄 취소되지는 않는다.
- 결정 기록: 없음

## USER-007 작가 신청

- 규칙: 가입한 회원의 기본 역할은 `USER`다. 이용 가능한 일반 회원은 신청 시점에 공개 중인 본인 게시물의 받은 좋아요가 합계 100개 이상이면 `ARTIST` 역할을 얻는다. 공개 범위는 [POST-007](post.md#post-007-공개-범위), 좋아요는 [LIKE-004](like.md#like-004-표시와-집계)에 따라 게시물에 표시되는 수를 적용한다.
- 좋아요 합계에는 [작성자가 자신의 게시물에 등록한 좋아요](like.md#like-002-대상-게시물)도 포함한다.
- [탈퇴한 회원이 남긴 좋아요](#user-006-탈퇴-후-게시물과-좋아요)도 현재 공개 중인 게시물의 좋아요 수에 남아 있으면 합계에 포함한다.
- 작가가 된 뒤 게시물을 삭제하거나 좋아요가 취소되어 합계가 100개 미만으로 내려가도 작가 역할은 유지된다.
- 적용 범위: 내 회원 정보 및 작가 신청 자격 조회, 작가 신청
- 예외: 이미 작가인 회원과 정지 회원은 자격을 조회할 수 있으며 신청할 수 없다. 탈퇴 회원은 조회와 신청을 할 수 없다. [관리자가 작가 권한을 회수한 회원](admin.md#admin-002-회원-상태-관리)은 일반 회원과 같은 조건으로 다시 신청할 수 있다.
- 결정 기록: [작가 신청](../decisions/2026-11-11-artist-application.md), [관리자 작가 권한 변경](../decisions/2026-11-12-admin-artist-role-grant.md)
