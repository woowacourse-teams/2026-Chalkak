# 게시물 규칙

## POST-001 작성 자격

- 규칙: 로그인했고 정상 이용이 가능한 회원만 게시물 사진을 업로드하고 게시물을 작성할 수 있다.
- 적용 범위: 게시물 이미지 업로드 권한 발급, 게시물 생성
- 예외: 이용이 정지된 회원은 조회와 본인 게시물 삭제만 할 수 있다.
- 결정 기록: 없음

## POST-002 작성 가능 기간

- 규칙: 삭제되지 않은 주제가 `OPEN`인 동안만 게시물을 작성할 수 있다. 가능 여부는 서버가 생성 요청을 검증하는 시각으로 판단한다.
- 적용 범위: 게시물 생성
- 예외: 사진의 촬영 시각과 촬영·앨범 선택 여부는 검사하지 않는다.
- 결정 기록: 없음

## POST-003 주제별 게시물 수

- 규칙: 한 회원은 한 주제에 `VALIDATING`, `PENDING`, `APPROVED` 게시물 중 하나만 가질 수 있다. 동시 요청도 최종 한 건만 성공한다.
- 적용 범위: 게시물 생성, 중복 제출
- 예외: `REJECTED` 또는 삭제된 게시물은 슬롯을 차지하지 않아 참여 기간이 남아 있으면 다시 제출할 수 있다.
- 결정 기록: 없음

## POST-004 사진 업로드

- 규칙: 게시물에는 발급받은 본인 소유의 사진 업로드 한 건을 한 번만 연결할 수 있다. 업로드 입력은 WebP이며 최대 5 MiB다.
- 적용 범위: 게시물 사진 업로드, 게시물 생성
- 예외: 업로드 URL은 5분, 게시물에 연결할 수 있는 업로드 ID는 발급 후 1시간까지 유효하다.
- 결정 기록: 없음

## POST-005 제목 입력

- 규칙: 제목은 선택 사항이며 Unicode code point 기준 최대 10자다. `null`, 빈 문자열, 공백만 있는 값은 제목 없음인 `null`로 저장한다.
- 적용 범위: 게시물 생성
- 예외: 내용이 있는 제목의 앞뒤 공백은 제거하지 않고 길이에 포함한다. 별도 설명 필드는 제공하지 않는다.
- 결정 기록: 없음

## POST-006 이미지 처리와 검수 상태

- 규칙: 이미지 처리 전 게시물은 `VALIDATING`, 처리 성공 후에는 `PENDING`이 된다. 이미지 처리 실패 또는 관리자 반려는 `REJECTED`, 관리자 승인은 `APPROVED`로 전이한다.
- 적용 범위: 게시물 생성, 이미지 처리 콜백, 관리자 검수
- 예외: 참여 기간 안에 생성된 게시물은 기간이 끝난 뒤에도 이미지 처리와 관리자 검수를 계속할 수 있다. 중복되거나 늦게 도착한 콜백은 이미 확정된 상태를 되돌리지 않으며, 처리 제한시간이 지난 `VALIDATING` 게시물은 같은 주제로 다시 제출할 때 `REJECTED`로 전환한다.
- 결정 기록: 없음

## POST-007 공개 범위

- 규칙: `APPROVED`이고 게시물·주제·사진·작성자가 모두 삭제되지 않은 게시물만 공개한다.
- 적용 범위: 피드, 게시물 상세, 캘린더, 좋아요 대상 확인
- 예외: 피드는 로그인 없이 조회할 수 있지만 상세와 캘린더는 로그인이 필요하다. 작성자 본인도 승인 전 게시물을 상세·피드·캘린더에서 조회할 수 없다.
- 결정 기록: 없음

## POST-008 피드 정렬과 표시 정보

- 규칙: 피드는 주제 날짜별로 최신순·인기순·랜덤순을 제공하며 사진, 현재 사인, 제목, 제출 시각, 좋아요 수를 표시한다. 로그인 사용자는 내 좋아요 여부와 내 게시물 여부도 확인한다.
- 적용 범위: 게시물 피드
- 예외: 최신순은 제출 시각, 인기순은 좋아요 수와 제출 시각 순으로 정렬한다. 비로그인 사용자의 내 좋아요 여부와 내 게시물 여부는 `false`이며, 랜덤순은 첫 응답의 seed를 다음 페이지에도 사용한다. 랜덤순의 두 번째 페이지부터 seed가 필수이며, 다른 정렬에는 seed를 지정할 수 없다. KST 기준 미래 날짜의 피드는 조회할 수 없다.
- 결정 기록: 없음

## POST-009 캘린더

- 규칙: 로그인한 회원은 월 단위로 자신의 `APPROVED` 게시물만 조회한다. 날짜는 제출·승인 시각이 아니라 주제 날짜를 사용한다.
- 적용 범위: 내 게시물 캘린더
- 예외: 승인 전, 반려, 삭제된 게시물은 표시하지 않는다.
- 결정 기록: 없음

## POST-010 삭제와 수정

- 규칙: 작성자 본인은 `PENDING`, `APPROVED` 게시물을 삭제할 수 있다. 삭제하면 게시물과 사진을 논리 삭제하고 연결된 좋아요를 제거한다.
- 적용 범위: 사용자 게시물 삭제
- 예외: `VALIDATING`, `REJECTED` 게시물은 사용자가 삭제할 수 없다. 삭제는 복구할 수 없고 반복 요청은 최초 삭제 결과를 유지한다. 실제 미디어 파일은 삭제 요청에서 제거하지 않으며, 현재 게시물 수정 기능은 제공하지 않는다.
- 결정 기록: 없음
