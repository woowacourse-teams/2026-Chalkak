# 게시물 규칙

## POST-001 작성 자격

- 규칙: 로그인했고 정상 이용이 가능한 회원만 게시물 사진을 업로드하고 게시물을 작성할 수 있다.
- 적용 범위: 게시물 이미지 업로드 권한 발급, 게시물 생성
- 예외: 이용이 정지된 회원은 조회와 본인 게시물 삭제만 할 수 있다.
- 결정 기록: 없음

## POST-002 작성 가능 기간

- 규칙: 삭제되지 않은 주제가 `OPEN`인 동안만 게시물을 작성할 수 있다. 가능 여부는 서버가 생성 요청을 검증하는 시각으로 판단한다.
- 적용 범위: 게시물 생성
- 예외: 사진의 촬영 시각과 촬영·앨범 선택 여부는 검사하지 않는다.
- 결정 기록: 없음

## POST-003 주제별 게시물 수

- 규칙: 한 회원은 한 주제에 `VALIDATING`, `PENDING`, `APPROVED` 게시물 중 하나만 가질 수 있다. 동시 요청도 최종 한 건만 성공한다.
- 적용 범위: 게시물 생성, 중복 제출
- 예외: `REJECTED` 또는 삭제된 게시물은 슬롯을 차지하지 않아 참여 기간이 남아 있으면 다시 제출할 수 있다.
- 결정 기록: 없음

## POST-004 사진 업로드

- 규칙: 게시물에는 발급받은 본인 소유의 사진 업로드 한 건을 한 번만 연결할 수 있다. 업로드 입력은 WebP이며 최대 5 MiB다.
- 적용 범위: 게시물 사진 업로드, 게시물 생성
- 예외: 업로드 URL은 5분, 게시물에 연결할 수 있는 업로드 ID는 발급 후 1시간까지 유효하다.
- 결정 기록: 없음

## POST-005 제목 입력

- 규칙: 제목은 선택 사항이며 Unicode code point 기준 최대 10자다. `null`, 빈 문자열, 공백만 있는 값은 제목 없음인 `null`로 저장한다.
- 적용 범위: 게시물 생성
- 예외: 내용이 있는 제목의 앞뒤 공백은 제거하지 않고 길이에 포함한다. 별도 설명 필드는 제공하지 않는다.
- 결정 기록: 없음

## POST-006 이미지 처리와 검수 상태

- 규칙: 이미지 처리 전 게시물은 `VALIDATING`, 처리 성공 후에는 `PENDING`이 된다. 이미지 처리 실패 또는 관리자 반려는 `REJECTED`, 관리자 승인은 `APPROVED`로 전이한다.
- 적용 범위: 게시물 생성, 이미지 처리 콜백, 관리자 검수
- 예외: 참여 기간 안에 생성된 게시물은 기간이 끝난 뒤에도 이미지 처리와 관리자 검수를 계속할 수 있다. 중복되거나 늦게 도착한 콜백은 이미 확정된 상태를 되돌리지 않으며, 처리 제한시간이 지난 `VALIDATING` 게시물은 같은 주제로 다시 제출할 때 `REJECTED`로 전환한다.
- 결정 기록: 없음

## POST-007 공개 범위

- 규칙: `APPROVED`이고 게시물·주제·사진·작성자가 모두 삭제되지 않은 게시물만 공개한다.
- 적용 범위: 피드, 게시물 상세, 작성자별 공개 사진 목록, 캘린더, 좋아요 대상 확인
- 예외: 피드는 로그인 없이 조회할 수 있지만 상세와 작성자별 공개 사진 목록, 캘린더는 로그인이 필요하다. 작성자 본인은 캘린더에서 자신의 `PENDING` 게시물도 조회할 수 있다. 승인 전 게시물은 작성자 본인도 상세·피드·작성자별 공개 사진 목록에서 조회할 수 없다.
- 결정 기록: [캘린더에 승인 대기 게시물 표시](../decisions/2026-09-18-calendar-pending-posts.md), [작성자별 최근 공개 사진 조회](../decisions/2026-10-19-author-recent-public-posts.md)

## POST-008 피드 정렬과 표시 정보

- 규칙: 피드는 주제 날짜별로 최신순·인기순·랜덤순을 제공하며 사진, 작성자의 회원 ID인 `authorId`, 현재 사인, 제목, 제출 시각, 좋아요 수를 표시한다. 로그인 사용자는 내 좋아요 여부와 내 게시물 여부도 확인한다.
- 적용 범위: 게시물 피드
- 예외: 최신순은 제출 시각, 인기순은 좋아요 수와 제출 시각 순으로 정렬한다. `authorId`는 비로그인 피드에도 항상 제공하며 조회자의 ID와 구분한다. 비로그인 사용자의 내 좋아요 여부와 내 게시물 여부는 `false`이며, 랜덤순은 첫 응답의 seed를 다음 페이지에도 사용한다. 랜덤순의 두 번째 페이지부터 seed가 필수이며, 다른 정렬에는 seed를 지정할 수 없다. KST 기준 미래 날짜의 피드는 조회할 수 없다.
- 결정 기록: [작성자 ID로 사인과 공개 사진 목록 연결](../decisions/2026-10-19-post-author-id-public-navigation.md)

## POST-009 캘린더

- 규칙: 로그인한 회원은 월 단위로 자신의 `PENDING`, `APPROVED` 게시물을 조회하며 각 게시물의 썸네일 URL과 실제 검수 상태를 받는다. 날짜는 제출·승인 시각이 아니라 주제 날짜를 사용한다.
- 기록 연월: 현재 캘린더에서 볼 수 있는 본인의 게시물이 있는 연월 목록을 별도로 조회할 수 있다. 연월 입력 없이 전체 기간의 주제 날짜를 기준으로 중복을 제거하고 연도·월 최신순으로 반환한다. 기록이 없으면 빈 목록을 반환하며, 기록이 없는 현재 달을 임의로 포함하지 않는다. 이 목록은 기록 여부를 표시하기 위한 정보로, 빈 달의 선택이나 월별 조회를 제한하지 않는다.
- 적용 범위: 내 게시물 캘린더, 캘린더 기록 연월 목록
- 예외: `VALIDATING`, `REJECTED` 게시물과 게시물·주제·사진·작성자가 삭제된 경우는 표시하지 않는다.
- 결정 기록: [캘린더에 승인 대기 게시물 표시](../decisions/2026-09-18-calendar-pending-posts.md), [캘린더 기록 연월 목록 제공](../decisions/2026-09-19-calendar-recorded-months.md)

## POST-011 작성 여부 사전 확인

- 규칙: 로그인한 회원은 작성 화면에 들어가기 전에, 지금 참여할 수 있는 주제에 이미 게시물을 썼는지 확인할 수 있다. 대상 주제는 주제 날짜가 아니라 요청 시각의 참여 기간으로 정한다.
- 적용 범위: 게시물 작성 진입
- 예외: 판정은 POST-003과 같아서 `VALIDATING`, `PENDING`, `APPROVED` 게시물이 있으면 작성함으로 답하고, `REJECTED`와 삭제된 게시물은 슬롯을 차지하지 않는다. 이미지 처리 대기 시간을 넘긴 `VALIDATING` 게시물도 다시 쓸 수 있으므로 작성함으로 답하지 않는다. 지금 참여할 수 있는 주제가 없으면 주제를 찾을 수 없는 것으로 응답한다. 확인 결과는 조회 시점의 것이며 작성 가능 여부를 보장하지 않는다.
- 결정 기록: 없음

## POST-010 삭제와 수정

- 규칙: 작성자 본인은 `PENDING`, `APPROVED` 게시물을 삭제할 수 있다. 삭제하면 게시물과 사진을 논리 삭제하고 연결된 좋아요를 제거한다.
- 적용 범위: 사용자 게시물 삭제
- 예외: `VALIDATING`, `REJECTED` 게시물은 사용자가 삭제할 수 없다. 삭제는 복구할 수 없고 반복 요청은 최초 삭제 결과를 유지한다. 실제 미디어 파일은 삭제 요청에서 제거하지 않으며, 현재 게시물 수정 기능은 제공하지 않는다.
- 결정 기록: 없음

## POST-012 작성자별 공개 사진 조회

- 규칙: 로그인한 회원은 지정한 작성자의 공개 사진을 전체 기간에서 주제 날짜 최신순으로 조회한다. 조회 개수는 기본 20개이며 `pageSize`로 1~100개를 지정할 수 있고, 범위 밖이거나 숫자가 아닌 값은 잘못된 조회 조건으로 거절한다. 각 사진은 게시물 ID, 원본·썸네일 URL, 주제 ID·제목·날짜를 제공한다. 공개 조건은 POST-007을 따른다.
- 적용 범위: 작성자별 최근 공개 사진 목록
- 이어보기: `page`는 1부터 시작하며 생략하면 1페이지를 조회한다. 1보다 작거나 숫자가 아닌 페이지는 잘못된 조회 조건으로 거절한다. 응답은 `currentPage`, `pageSize`, `hasNext`, `posts`를 제공하며 마지막 페이지와 빈 목록은 `hasNext=false`다. 범위를 벗어난 페이지도 요청한 페이지 번호·크기와 빈 목록을 반환한다. 다음 페이지는 같은 `pageSize`와 `currentPage + 1`로 조회한다. 커서 입력·응답은 제공하지 않는다.
- 조회 중 변경: 각 요청 시점의 공개 사진과 정렬 순서로 페이지를 구성하며 목록 스냅샷을 고정하지 않는다. 조회 도중 승인·삭제로 사진이 앞뒤 페이지로 이동하여 중복되거나 건너뛰는 경우를 허용한다. 새로고침·재진입은 1페이지부터 다시 조회한다.
- 예외: 정지 회원도 조회할 수 있으며 정지된 작성자의 사진도 공개 조건을 충족하면 포함한다. 본인 조회에도 승인 대기·반려 사진은 포함하지 않는다. 정상 회원에게 공개 사진이 없으면 빈 목록을 반환하고, 없거나 탈퇴한 작성자는 찾을 수 없음으로 처리한다. 사진 제목·좋아요·사인 등 상세 정보는 목록에 포함하지 않는다. 썸네일이 없는 기존 사진은 썸네일 URL이 없을 수 있다.
- 결정 기록: [작성자별 최근 공개 사진 조회](../decisions/2026-10-19-author-recent-public-posts.md), [작성자 공개 사진의 페이지 번호 이어보기](../decisions/2026-10-19-author-public-post-pagination.md)
