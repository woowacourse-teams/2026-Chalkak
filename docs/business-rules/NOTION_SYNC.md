# Notion 수동 반영 안내

현재 규칙을 추가·수정·삭제한 작업의 종료 안내를 작성할 때 읽는다. Codex·Claude와 앱·CLI 모두 같은 방식으로 안내하며 Notion 조회·수정, 화면 제어, 완료 추적은 하지 않는다.

## 작성 순서

1. 이번 작업에서 실제로 달라진 규칙 ID만 확인한다. 템플릿·절차·설정·결정 기록만 바뀌었다면 안내하지 않는다.
2. [위치 목록](notion-map.yml)에서 공통 경로, 도메인, 페이지 이름을 찾는다. 새 규칙은 기존 페이지에 추가할지 새 페이지를 만들지 명시한다.
3. 작업 종료 응답에 **위치 → 추가·교체·삭제 → 대상 → 완성 문구** 순서로 안내한다. 여러 변경은 위치 목록의 도메인·페이지 순서를 따른다.
4. 변경하지 않은 표·문장·순서를 유지하도록 알린다. URL·계정·페이지 ID를 만들지 않고 결정 기록은 Notion에 복사하지 않는다.

## 예시

> **Notion 수동 반영이 필요합니다.**
>
> 1. `찰캌 → 백엔드 → 비즈니스 룰 → 백엔드 비지니스 룰`을 엽니다.
> 2. `사인 → 사인 교체` 페이지를 엽니다.
> 3. 기존 예외 문장에 다음 내용을 추가합니다: “처리 중인 같은 업로드 ID의 반복 요청은 새 처리를 시작하지 않고 현재 활성 사인을 반환합니다.”
> 4. 나머지 내용과 순서는 그대로 유지합니다.
