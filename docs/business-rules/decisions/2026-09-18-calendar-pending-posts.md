# POST-007·POST-009 캘린더에 승인 대기 게시물 표시

- 결정일: 2026-09-18
- 상태: 확정
- 변경 전: 내 게시물 캘린더는 `APPROVED` 게시물만 표시했다.
- 변경 후: 내 게시물 캘린더에서 본인의 `PENDING`, `APPROVED` 게시물의 썸네일 URL과 실제 검수 상태를 반환한다. `VALIDATING`, `REJECTED`와 삭제된 게시물·주제·사진·작성자는 제외한다.
- 변경 이유: 사진을 제출한 사용자가 관리자 승인 전에도 달력에서 본인의 제출 사진을 확인할 수 있게 한다.
- 영향 범위: 내 게시물 캘린더. 피드·상세·좋아요의 공개 조건과 기존 월별 조회·정렬·인증 조건은 유지한다.
