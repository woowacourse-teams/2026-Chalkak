# BANNER-006 앱 배너 공개 목록

- 결정일: 2026-10-19
- 상태: 확정
- 변경 전: 관리자만 배너 목록을 조회할 수 있다.
- 변경 후: 앱에 토큰 없이 또는 유효한 회원·관리자 토큰으로 조회하는 목록 API를 제공한다. 미삭제 배너만 최신순으로 반환하며 페이지 기본값·경계·응답 필드는 관리자 목록과 같다. 관리자 화면도 같은 공개 목록을 사용한다.
- 변경 이유: 비로그인 상태에서도 홍보 배너를 표시하고 응답의 URL을 웹뷰로 열 수 있도록 한다. 관리자 조회 코드를 앱에서 의존하거나 복제하지 않도록 공통 조회 서비스와 결과 타입을 banner에 둔다.
- 영향 범위: GET /api/v1/banners 공개 접근·OpenAPI·앱 연동. 배너 GET에 한정해 익명·USER·ADMIN을 허용하며 회원 개인화·계정 상태 조회는 하지 않는다. 관리자 등록·삭제 계약과 DB 구조는 유지한다. 동일한 목록 GET과 DTO를 합치기로 합의했다. 사용자가 배포된 클라이언트 사용처가 없고 제거해도 된다고 확인해 기존 GET /api/v1/admin/banners를 제거한다. 조회 조건·응답·공개 범위가 같으므로 공통 GET과 DTO를 재사용한다. 상세 조회·클라이언트 화면 구현은 제외한다.
