# NOTIFICATION-005 로그인별 등록 유지와 해제 시 연결 제거

- 결정일: 2026-10-06
- 상태: 확정
- 변경 전: 수정 #491에서 앱 설치 UUID와 플랫폼을 등록하고 같은 설치의 행을 재사용하는 방향을 합의했다. 기존 구현은 해제 시 회원·로그인 연결을 남기고 토큰만 제거했다.
- 변경 후: 설치 UUID와 플랫폼을 추가하지 않고 JWT의 로그인 ID와 FCM 토큰으로 등록한다. 활성 연결의 토큰 변경은 기존 행을 갱신한다. 비활성화 시 회원·로그인·FCM 원문·해시 연결을 제거한다. 이후 재등록은 새 행을 생성한다. 별도 로그인 테이블 제거와 계정 단위 주제·승인/반려 두 설정은 유지한다.
- 변경 이유: 현재 발송 요구에 설치 행의 지속적인 재사용과 플랫폼별 발송 분기가 필수는 아니다. 행 재사용을 위해 앱의 식별자 생성·보관과 필수 API 입력을 추가하는 부담을 줄인다.
- 영향 범위: 기기 엔티티, 해제 쿼리, DB 이관·제약, 회귀 테스트와 앱 연동 안내. 등록 요청은 기존 `{"fcmToken":"..."}`과 빈 204 응답을 유지한다. 플랫폼 필드는 실제 운영 API에 추가하기 전에 제거했다.
- 관련 규칙: NOTIFICATION-005
- 관련 이슈·PR: [#491](https://github.com/woowacourse-teams/2026-Chalkak/issues/491), [#508](https://github.com/woowacourse-teams/2026-Chalkak/pull/508)

## 같은 날 추가 리뷰 반영: 해제된 행을 남기지 않는다

- 변경 전: 기기 해제 시 회원·로그인·토큰 연결을 NULL로 지우고 식별자와 등록·갱신·비활성화 시각만 남겼다.
- 변경 후: 해제 시 기기 행을 삭제한다. 저장된 기기의 회원·로그인·토큰은 모두 필수이며, 같은 토큰은 하나의 기기에만 연결한다. 반복 해제는 기기가 없는 상태를 유지한다. 재등록은 새 행을 만든다.
- 변경 이유: 연결이 제거된 행을 조회하거나 재사용하는 기능과 보관·정리 목적이 없고, 로그아웃·재로그인마다 행이 누적된다. 사용자가 리뷰의 행 삭제 방향을 승인했다. 해제된 기기의 과거 시각을 이 테이블에서 조사하는 기능은 제공하지 않는다.
- 영향 범위: 기기 해제 쿼리·엔티티·생성 SQL·회귀 테스트·NOTIFICATION-005와 앱 안내. RT 폐기와 기기 삭제의 같은 트랜잭션 처리, 다른 로그인 유지, 앱 요청·응답 계약은 유지한다.
