# NOTIFICATION-005 로그인별 등록 유지와 해제 시 연결 제거

- 결정일: 2026-10-06
- 상태: 확정
- 변경 전: 수정 #491에서 앱 설치 UUID와 플랫폼을 등록하고 같은 설치의 행을 재사용하는 방향을 합의했다. 기존 구현은 해제 시 회원·로그인 연결을 남기고 토큰만 제거했다.
- 변경 후: 설치 UUID와 플랫폼을 추가하지 않고 JWT의 로그인 ID와 FCM 토큰으로 등록한다. 활성 연결의 토큰 변경은 기존 행을 갱신한다. 비활성화 시 회원·로그인·FCM 원문·해시 연결을 제거한다. 이후 재등록은 새 행을 생성한다. 별도 로그인 테이블 제거와 계정 단위 주제·승인/반려 두 설정은 유지한다.
- 변경 이유: 현재 발송 요구에 설치 행의 지속적인 재사용과 플랫폼별 발송 분기가 필수는 아니다. 행 재사용을 위해 앱의 식별자 생성·보관과 필수 API 입력을 추가하는 부담을 줄인다.
- 영향 범위: 기기 엔티티, 해제 쿼리, DB 이관·제약, 회귀 테스트와 앱 연동 안내. 등록 요청은 기존 `{"fcmToken":"..."}`과 빈 204 응답을 유지한다. 플랫폼 필드는 실제 운영 API에 추가하기 전에 제거했다.
