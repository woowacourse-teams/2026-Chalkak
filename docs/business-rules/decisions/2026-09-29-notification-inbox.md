# NOTIFICATION-001~004 검수 결과 알림함 도입과 보관 기준

- 결정일: 2026-09-29
- 상태: 확정
- 변경 전: 관리자 검수 결과가 게시물 상태와 감사 로그에만 반영되고, 작성자가 조회할 알림함 기록은 없었다.
- 변경 후: 승인·반려 검수를 확정할 때 같은 트랜잭션에서 작성자 알림 한 건을 저장한다. 작성자는 본인 알림의 목록·상세·미읽음 여부를 조회하고 읽음 처리할 수 있다. 일반 회원의 알림은 생성 후 60일, 탈퇴 회원의 남은 알림은 탈퇴 후 30일이 지나면 삭제한다.
- 변경 이유: 검수 결과와 알림이 서로 어긋나지 않도록 저장을 묶고 사건별 중복을 막는다. 알림함의 사진은 목록에서 썸네일, 상세에서 원본을 제공한다. 처음 논의한 알림함 30일과 후속 Outbox 60일은 연결·삭제 순서가 충돌할 수 있어 일반 알림의 보관 기간을 생성 시각부터 60일로 맞췄다. 탈퇴 직전 발송 장애 조사에 필요한 기록은 탈퇴 후 30일 동안 함께 보관하기로 했다.
- 영향 범위: 관리자 승인·반려 트랜잭션, 회원 알림함 API, 읽음 표시, 주기적 데이터 정리. 주제 알림·기기 등록·FCM·SQS·Outbox는 후속 이슈 범위이며 이번 결정의 구현 완료 대상으로 보지 않는다.
