# POST-007·POST-012 작성자별 최근 공개 사진 조회

- 결정일: 2026-10-19
- 상태: 확정
- 변경 전: 주제 날짜별 피드·게시물 상세·본인 캘린더를 제공하며, 다른 작성자의 전체 기간 사진을 모아서 조회할 수 없었다.
- 변경 후: 로그인한 회원은 작성자 ID로 공개 사진을 주제 날짜 최신순으로 기본 20개 조회하며 `pageSize`로 1~100개를 지정할 수 있다. 사진·게시물 ID·주제만 제공하고 자세한 정보는 기존 게시물 상세 조회를 사용한다. 승인 대기·반려·삭제된 자원은 기존 공개 조건에 따라 제외한다. 사진이 없는 정상 회원은 빈 목록, 없거나 탈퇴한 작성자는 찾을 수 없음으로 구분한다.
- 변경 이유: 사인에서 작성자의 사진을 탐색하는 기능을 단계적으로 제공한다. 주제는 날짜마다 하나이고 참여 기간이 겹치지 않으므로 주제 날짜로 사용자가 이해할 수 있는 순서를 정한다. 모아보기의 최소 정보와 상세 조회를 분리하고, 현재 상세 API처럼 로그인한 회원에게 제공한다. 개발 검토에서 고정 20개 대신 기존 피드와 같은 기본값 20·허용 범위 1~100의 요청 계약을 선택했다.
- 영향 범위: 새 `GET /api/v1/users/{userId}/posts`, 관련 게시물 규칙·Swagger·앱 연동 설명서. 기존 피드·상세·캘린더의 계약과 사인 표시 규칙은 유지한다.
- 관련 규칙: POST-007, POST-012, TOPIC-002, TOPIC-003, USER-002, USER-006
- 관련 이슈·PR: [상위 #679](https://github.com/woowacourse-teams/2026-Chalkak/issues/679), [이번 작업 #680](https://github.com/woowacourse-teams/2026-Chalkak/issues/680)

커서로 과거 사진을 이어 보는 기능은 #681, 피드·상세 응답의 작성자 ID 제공과 사인 클릭 연결은 #682에서 별도로 구현한다. 이 결정의 현재 제공 범위는 요청한 개수만큼의 최근 사진 조회다.
