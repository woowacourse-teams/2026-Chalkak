# APPVERSION-004~006 관리자 입력 검증과 안전한 변경

- 결정일: 2026-10-29
- 상태: 확정
- 변경 전: 공개 조회와 미설정 시 이용 허용만 제공하고 관리자 입력·감사·복구 정책은 미확정이었다.
- 변경 후: 관리자가 플랫폼별로 최초 입력·수정한다. 버전은 각 자리 0~2,147,483,647, 앞자리 0 금지의 세 숫자이며, 주소는 공식 스토어 형식을 검증한다. 실제 자사 앱·설치 가능 여부는 관리자가 확인한다. 사유는 공백 제거 후 1~500자이다. 버전 하향을 허용하고 같은 값은 이력·시각을 유지한다. 다른 값의 오래된 요청은 revision 충돌로 거절하며 변경과 감사 기록은 함께 반영한다.
- 변경 이유: 초기 운영값을 개발·배포에 넣지 않고 관리자가 입력하게 한다는 요구를 반영했다. 잘못 높인 버전의 복구와 재시도 시 이력 중복 방지가 필요하며, 고정된 실제 앱 ID가 없어 앱 ID의 형식 검증과 관리자 확인을 구분하기로 사용자가 합의했다. 단순 URL 형식 확인으로 출시 가능 여부를 보장하지 않는다.
- 영향 범위: 관리자 웹 연동, 서버 입력 검증, 감사 이력, Android·iOS 공개 조회에 반영되는 값
- 관련 규칙: APPVERSION-002, APPVERSION-004, APPVERSION-005, APPVERSION-006, ADMIN-006, ADMIN-007
