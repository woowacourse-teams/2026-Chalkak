# APPVERSION-001 관리자 입력 전에는 업데이트 제한을 적용하지 않는다

- 결정일: 2026-10-28
- 상태: 확정
- 변경 전: 앱 최소 지원 버전 조회 기능이 없었다. 초기 이슈 초안에는 실제 버전과 주소를 개발 전에 확정해 초기 데이터로 넣는 방향을 적었다.
- 변경 후: 버전과 주소는 관리자가 최초 입력·수정한다. 공개 조회에는 운영 초기값을 넣지 않으며, 설정이 없으면 200과 버전·주소의 null을 반환한다. 앱은 이때 업데이트 제한 없이 이용을 허용한다. 설정이 있으면 숫자 단위 버전 비교와 스토어 이동 계약을 따른다.
- 변경 이유: 사용자가 두 값을 관리자 페이지에서 입력하는 요구를 다시 확인했고, 최초 입력 전에는 업데이트 제한 없이 이용하도록 선택했다. 개발 시점에 예시 버전이나 주소를 운영값으로 고정할 이유가 없다.
- 영향 범위: 비로그인 조회, 플랫폼별 미설정 응답, 앱의 nullable 필드 처리와 버전 비교. 관리자 저장 API·화면은 후속 작업이다. 통신 실패를 미설정과 동일한 상황으로 확정하지 않는다.
