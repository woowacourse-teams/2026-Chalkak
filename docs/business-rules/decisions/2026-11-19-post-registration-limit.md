# POST-003 하루 총 10회 등록과 기존 게시물 집계

- 결정일: 2026-11-19
- 상태: 확정 · 구현 중, 미배포
- 변경 전: 주제별 활성 게시물 한 건을 유지하되 삭제·반려 뒤 재등록에 별도 일일 상한이 없었다.
- 변경 후: KST 하루에 최초 등록 포함 총 10회까지 생성한다. 삭제·반려·생성 뒤 이미지 처리 실패도 사용 횟수이며 생성 전 실패·롤백은 제외한다. 다음 KST 날짜에 초기화한다. 제목·설명 수정과 검수 재시도는 등록 횟수를 추가 사용하지 않는다.
- 변경 이유: 삭제 후 재등록의 사용자 흐름을 유지하면서 반복 등록에 따른 이미지 처리·검수 호출의 증가를 제한한다. 별도 일일 카운터를 동기화하기보다 삭제된 행도 보존하는 기존 posts를 집계한다.
- 영향 범위: 게시물 생성에서 회원 행 쓰기 잠금으로 한도 확인과 생성을 직렬화한다. 앱은 추가된 본인 등록 한도 API로 잔여 횟수와 초기화 시각을 조회하며 삭제 전 비복구 고지를 보여준다. 기존 오늘 작성 여부의 의미와 응답은 유지한다. 원래 주제별 한 건·작성 기간·인증 정책도 유지한다.
- 날짜 경계: 잠금을 획득하고 생성 요청의 한도를 검증한 시각을 created_at으로 저장한다. 저장·커밋 도중 자정을 지나더라도 같은 요청의 집계 날짜가 바뀌지 않게 한다.
- 관련 규칙: [POST-003](../rules/post.md#post-003-주제별-게시물-수)
- 관련 이슈·PR: [#1056](https://github.com/woowacourse-teams/2026-Chalkak/issues/1056), PR 미등록

한도 조회는 현재 사용량 안내이며 예약이 아니다. 조회 후 다른 생성 요청이 먼저 성공하면 최종 생성은 거절될 수 있다. 운영 반영은 구현·검증·병합·배포와 구분한다.
