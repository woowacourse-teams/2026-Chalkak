# FEEDBACK-005·ADMIN-006·007 관리자 문의 삭제와 감사

- 결정일: 2026-11-03
- 상태: 확정
- 변경 전: 사용자만 본인 문의를 소프트 딜리트할 수 있고 관리자는 전체·사용자별 목록과 상세만 조회했다.
- 변경 후: `DELETE /api/v1/admin/feedbacks/{feedbackId}`에서 관리자가 문의를 소프트 딜리트하고 감사 기록을 같은 트랜잭션으로 저장한다. 정상·정지·탈퇴 회원의 문의 모두 대상이며, 원문은 관리자 조회에 보존한다. 성공은 본문 없는 204이고 요청 본문·별도 사유는 없다. 문의가 없으면 기존 404 오류, 잘못되거나 축약된 UUID는 400으로 거절한다.
- 변경 이유: 관리자에게 불필요한 문의를 숨길 수단을 제공하면서도 누가 어떤 문의를 삭제했는지 보존하고, 감사가 누락된 삭제를 방지한다. 조회와 독립적으로 완성할 수 있어 #904에서 #921로 분리했다.
- 영향 범위: 문의 행 잠금으로 관리자·사용자 삭제를 직렬화한다. 이미 삭제된 문의는 최초 시각을 유지하고 새 감사 기록 없이 204로 처리한다. 감사에는 관리자·대상·행위·요청 식별자와 삭제 시각의 전후 값만 남기고 문의 원문·사용자 개인정보는 복사하지 않는다. 감사 실패 시 삭제도 롤백한다. 삭제된 문의는 본인 조회에서 숨기되 접수 제한에 계속 포함한다. 사용자 API 계약은 유지하며, 관리자 삭제로 상세가 사라져도 기존 404 처리로 연결한다. 답변·알림은 #905·#906의 후속 범위다.
