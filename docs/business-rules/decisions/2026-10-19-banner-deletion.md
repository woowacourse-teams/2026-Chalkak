# BANNER-003~005 배너 논리 삭제와 재등록

- 결정일: 2026-10-19
- 상태: 확정
- 변경 전: 관리자 배너 등록·목록 조회만 제공하고, 모든 저장된 배너 간 같은 URL을 거절한다.
- 변경 후: 사유를 포함한 관리자 논리 삭제를 제공한다. 삭제된 배너는 목록·URL 중복 대상에서 제외하고 새 ID로 재등록할 수 있다. 유효한 반복·동시 삭제는 최초 시각·감사 한 건을 유지하며 삭제와 감사는 함께 성공하거나 롤백된다. 외부 페이지·파일은 삭제하지 않는다.
- 변경 이유: 끝난 홍보 배너를 목록에서 내리면서 삭제 이력을 보존하고 같은 주소를 새 홍보에 사용할 수 있도록 한다. 삭제 사유는 기존 관리자 감사 로그에만 보관한다.
- 영향 범위: 관리자 삭제·목록·등록, 부분 URL 고유 제약, 감사 기록. 앱 공개 목록은 후속 #678에서 제공한다. 관리자 삭제 사유는 기존 감사 민감값 검증도 적용받는다.
