# FEEDBACK-003 본인 문의 목록과 기존 피드백 전환

- 결정일: 2026-11-03
- 상태: 확정
- 변경 전: 제출 회원은 본인 피드백을 조회할 수 없고 관리자만 전체 피드백을 조회했다.
- 변경 후: 정상·정지 회원은 삭제되지 않은 본인 문의 목록만 최신순으로 조회한다. 페이지 번호는 1부터 시작하고 페이지당 건수는 기본 20건·최대 100건이다. 도입 전 피드백은 같은 `feedbacks` 테이블에 보존하며 `deleted_at`을 채워 사용자 목록에서 제외한다. 삭제된 문의도 접수 제한 집계에는 포함한다.
- 변경 이유: 신규 고객센터에서 사용자별 비공개 내역을 제공하되, 기존 기록을 물리 삭제하거나 별도 보관 테이블·유형 컬럼을 만들지 않는다. 사용자가 기존 피드백의 소프트 딜리트를 제안해 이 방식으로 확정했다.
- 영향 범위: `GET /api/v1/feedbacks` 추가. 기존 제출 성공 계약과 관리자 전체 조회는 유지한다. 마이그레이션 적용 시점 이전 행에만 삭제 표시하며 새 문의는 기본 `NULL`이다. 사용자 삭제 API는 후속 커밋에서 구현한다.
