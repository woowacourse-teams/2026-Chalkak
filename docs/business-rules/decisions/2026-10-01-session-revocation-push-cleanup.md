# NOTIFICATION-005 재사용·만료 감지 시 푸시 기기 해제

- 결정일: 2026-10-01
- 상태: 확정
- 변경 전: 로그아웃·탈퇴는 RT 폐기와 기기 해제를 함께 처리하지만, 갱신 요청에서 재사용·만료를 감지하면 RT만 폐기하여 활성 기기와 FCM 토큰이 남는다.
- 변경 후: 갱신 요청에서 RT 재사용·비활동 만료·절대 만료를 감지해 로그인을 폐기할 때 해당 기기도 비활성화하고 FCM 원문·해시를 제거한다. 인증 오류 응답에도 두 정리를 함께 커밋한다. 기기 해제 저장이 실패하면 RT 폐기도 롤백한다. 정상 갱신과 다른 로그인은 유지한다.
- 변경 이유: PR 리뷰에서 로그인 폐기 경로의 기기 정리 누락을 발견했고, 사용자가 재사용·만료 시에도 기기를 해제하는 수정 방향을 승인했다. 종료된 로그인에 발송용 토큰이 남지 않도록 공통 폐기 경로를 사용한다.
- 영향 범위: 기존 POST `/api/v1/auth/refresh`의 응답·에러 코드는 유지한다. 앱의 추가 기기 해제 요청은 필요 없다. 토큰이 다른 로그인으로 이동했다면 새 연결과 기존 비활성화 시각은 유지한다. 만료 시각에 자동 해제하는 스케줄러를 추가하는 변경은 아니며, 갱신 요청에서 만료를 감지한 경우를 다룬다. 실제 FCM 발송은 후속 이슈 범위다. 기존에 이미 폐기되어 남은 활성 기기를 일괄 정리하는 작업은 포함하지 않는다.
