# POST-012·LIKE-004 작성자 공개 사진 목록의 좋아요 정보

- 결정일: 2026-10-26
- 상태: 확정
- 변경 전: 작성자 공개 사진 목록은 게시물 ID·이미지·주제만 제공하고 좋아요 정보는 포함하지 않았다.
- 변경 후: 각 항목에 피드와 같은 의미의 `likeCount`·`isLiked`를 추가한다. 개수는 전체 좋아요 수이고 상태는 인증된 조회자 본인의 좋아요 여부다. 0건은 `0`·`false`이며 본인 사진에도 같은 기준을 적용한다.
- 변경 이유: 사인을 눌러 진입한 작성자 사진 그리드에서도 피드·전시 카드와 같은 좋아요 정보를 표시하고 상세 화면과 동기화하기 위함이다. 앱 이슈 #813·#814의 요청을 백엔드 작업으로 반영한다.
- 영향 범위: `GET /api/v1/users/{userId}/posts` v1 응답의 하위 호환 필드 추가. 로그인 필수, 정지 회원 조회 허용, 탈퇴·없는 작성자 404, POST-007 공개 조건, 본인 조회의 승인 전 사진 제외, 최신순·페이지 계약은 유지한다. 비로그인 피드의 개수 제공·`isLiked=false`도 유지한다. 좋아요 등록·취소 자격과 부수효과는 변경하지 않는다. 앱 구현·병합·서버 배포는 이 결정과 별개다.
- 관련 규칙: POST-007, POST-012, LIKE-001, LIKE-002, LIKE-003, LIKE-004
- 관련 이슈·PR: #816, Android #813, iOS #814
