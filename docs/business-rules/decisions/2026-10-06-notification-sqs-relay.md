# NOTIFICATION-007 검수 알림의 SQS 발행과 재시도

- 결정일: 2026-10-06
- 상태: 확정
- 변경 전: 알림의 초기 발행 상태만 저장하고 실제 전달은 구현하지 않았다. 별도 Outbox 기반 전달 설계는 폐기했다.
- 변경 후: 알림 행의 발행 대기·다음 시도 시각을 이용해 SQS에 전달하고 수락 시각을 기록한다. 일시 오류·수락 여부 불명은 1분 뒤 재시도하며 사건 후 30분 정각부터 만료로 종료한다. 영구적인 요청·권한·설정 오류는 실패로 종료한다.
- 변경 이유: #492에서 합의한 재발행과 발송 기한을 별도 테이블 없이 구현한다. 개발 중 사용자가 DB → SQS 재시도 간격을 5분에서 1분으로 변경하도록 요청하여 반영한다. DB 저장과 SQS 수락을 하나의 원자적인 작업으로 만들 수 없으므로, 수락 이후 DB 반영 실패 시 중복 가능성을 받아들이고 동일 사건·알림 ID로 추적한다.
- 영향 범위: 승인·반려 알림 Relay, SQS 메시지와 발행 로그. 앱 API 계약 변경은 없다. 사용자가 개발 큐 URL을 제공하고 AWS 권한 확인 완료를 알렸으며, 실제 연동은 이번 PR의 PushWorker·FCM 구현 완료 후 개발 서버에서 검증하기로 했다. 실제 AWS 발행·기기 수신은 아직 미검증이고 FCM·PushWorker는 다음 단위다.
