# FEEDBACK-003 본인 문의 상세 조회

- 결정일: 2026-11-03
- 상태: 확정
- 변경 전: 본인 문의 목록만 제공했고 상세 조회는 제공하지 않았다.
- 변경 후: 정상·정지 회원은 삭제되지 않은 본인 문의 상세를 식별자·내용·UTC 접수 시각으로 조회할 수 있다. 타인·삭제·없는 문의는 같은 `404 / BUSINESS_ERROR / 문의를 찾을 수 없습니다.` 응답이며 원문·존재 여부를 노출하지 않는다. 인증하지 않았거나 탈퇴한 회원은 거절한다.
- 변경 이유: 승인한 고객센터의 비공개 조회 범위를 상세 화면에도 적용한다. 권한 없는 식별자의 존재 여부를 알려 주지 않도록 조회 조건에 소유권과 삭제 여부를 함께 적용한다.
- 영향 범위: `GET /api/v1/feedbacks/{feedbackId}` 추가. 기존 목록·제출 계약은 유지하고 UUID 형식 검증과 오류 응답 처리를 재사용한다. 사용자 문의 삭제·관리자 답변은 이번 단위에 포함하지 않는다.
