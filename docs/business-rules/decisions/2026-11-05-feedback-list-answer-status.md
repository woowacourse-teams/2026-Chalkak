# FEEDBACK-003 본인 문의 목록의 현재 답변 여부

- 결정일: 2026-11-05
- 상태: 확정
- 변경 전: 본인 문의 목록은 문의 식별자·내용·접수 시각만 제공하여 답변 여부는 상세에서 확인해야 했다.
- 변경 후: 목록 항목에 `hasAnswer` Boolean을 추가한다. 현재 유효한 답변이 있으면 true, 최초 미답변이거나 답변만 삭제됐으면 false다. 재답변하면 다시 true다. 답변 원문·등록 시각·삭제 이력은 목록에 노출하지 않는다.
- 변경 이유: 사용자가 문의별 상세를 열지 않고도 목록에서 답변 완료·미답변을 구분할 수 있게 한다. 삭제된 답변은 현재 상세 화면과 같은 미답변으로 표시한다.
- 영향 범위: `GET /api/v1/feedbacks`의 목록 응답에 필드를 추가한다. 기존 필드·정렬·페이지·권한과 상세 계약은 유지한다. Android·iOS는 목록 응답의 값으로 표시를 연결하며, 별도 DB 컬럼이나 상세 추가 호출은 필요하지 않다.
