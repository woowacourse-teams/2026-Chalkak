# NOTIFICATION-001 검수 알림의 발행 상태 저장

- 결정일: 2026-10-06
- 상태: 확정
- 변경 전: 검수 결과와 알림함 기록만 저장하며, 알림의 SQS 발행 필요 여부를 저장하지 않았다.
- 변경 후: 검수·감사 로그·알림을 저장하는 트랜잭션에서 알림 행의 초기 SQS 발행 상태도 저장한다. 생성 당시 승인·반려 수신 설정이 켜져 있고 탈퇴하지 않았으면 발행 대기, 그 외에는 발행 불필요로 저장한다. 정지 회원은 발행 대상에 포함한다. 발행 불필요 알림과 기존 알림은 설정을 켜도 소급 발송하지 않는다.
- 변경 이유: 알림함은 푸시 수신 설정에 관계없이 제공하면서, 업무 저장 후 발행할 대상을 서버 재시작 후에도 구분하기 위해서다. 별도 Outbox 대신 승인·반려 알림 행에 상태를 함께 저장하는 합의를 적용한다.
- 영향 범위: 알림 생성·DB 마이그레이션. 기존 목록·상세·읽음 API 계약은 유지한다. 실제 SQS 전달·FCM 발송 및 최신 조건 재검증은 후속 커밋에서 구현한다.
