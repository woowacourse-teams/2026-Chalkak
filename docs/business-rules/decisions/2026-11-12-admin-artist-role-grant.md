# ADMIN-002·006 관리자 작가 권한 부여

- 결정일: 2026-11-12
- 상태: 확정
- 변경 전: 관리자가 회원의 이용 정지를 관리할 수 있었고, 일반 회원의 작가 전환은 본인 신청으로 처리했다.
- 변경 후: 관리자는 사유를 남겨 탈퇴하지 않은 일반 회원에게 작가 역할을 부여할 수 있다. 정지 상태는 유지하고 원작 확약 동의는 회원이 직접 한다. 실제 역할 변경은 관리자와 대상, 사유, 변경 전후 역할을 감사 로그에 남기며 역할 변경과 함께 커밋된다.
- 변경 이유: 운영자가 작가 권한을 직접 부여할 경로를 열고, 본인만 할 수 있는 원작 확약 동의와 운영자의 권한 결정을 각각 기록한다.
- 영향 범위: 관리자 v1 회원 역할 변경과 감사 로그, 회원 v1 내 정보와 작가 동의 처리.
