# ADMIN-010 AI 프롬프트 미리보기 도입

- 결정일: 2026-10-19
- 상태: 확정
- 변경 전: 사진 리뷰용 AI 프롬프트를 서비스에서 실행해 볼 방법이 없어 프롬프트를 조정할 때마다 서버 밖에서 따로 실험해야 했다.
- 변경 후: 관리자가 저장하지 않은 프롬프트 초안(시스템 프롬프트, 사용자 프롬프트 템플릿, 모델, 호출 옵션)을 공개 게시물에 실행해 결과를 확인한다. 결과는 저장하지 않고 감사 로그도 남기지 않는다. 모델은 서버 허용 목록에서만 고를 수 있다. OpenAI 실패는 오류가 아니라 실패 유형·재시도 가능 여부를 담은 200 결과로 돌려준다.
- 변경 이유: 프롬프트 튜닝에서 OpenAI 실패는 실험의 결과이지 요청 오류가 아니므로 상태 코드로 나누지 않고 결과에 담는다(기존 예외 상태 코드 400·401·403·404 기준 유지). 저장·노출이 없는 읽기성 실행이라 감사 로그와 사용자 영향이 없고, 비용과 오용을 줄이기 위해 허용 모델과 공개 게시물로 범위를 제한한다. 모델의 점수 계산 규칙(종합 점수, 독특한 시각 판정 기준)은 프롬프트 버전별 값으로 두어 프롬프트 변경에 백엔드 배포가 필요 없게 한다.
- 영향 범위: 관리자 API 한 개(`POST /api/v1/admin/ai-prompt-previews`). DB·회원 API는 바뀌지 않는다. OpenAI 호출 비용이 발생하며 호출 지표는 구조화 로그로만 남긴다.
- 관련 규칙: ADMIN-010, ADMIN-001, POST-007
