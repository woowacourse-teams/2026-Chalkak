# FEEDBACK-003 기존 피드백 전환 시각 경계

- 결정일: 2026-11-03
- 상태: 확정
- 변경 전: 마이그레이션 실행 시 조회되는 기존 행 전체를 삭제 표시하여, 배포 중 구버전 앱이 접수한 기록도 경계 없이 숨길 수 있었다.
- 변경 후: 전환 마이그레이션의 DB 트랜잭션 시작 시각을 고정 기준으로 삼는다. `created_at < transaction_timestamp()`인 행만 숨긴다. 기준과 정확히 같거나 이후에 접수된 문의는 이전 앱이 저장했더라도 신규로 취급하며 사용자 조회에 남긴다.
- 변경 이유: PR 리뷰에서 지적한 blue/green 배포 중 접수 경계를 명확히 하고, 테이블 잠금 대기 후에도 기준 시각이 이동하지 않게 한다. 사용자가 잠금은 유지하고 추천 방향대로 리뷰를 반영하도록 승인했다.
- 영향 범위: 아직 병합하지 않은 전환 SQL과 경계 회귀 테스트, 배포 안내를 보완한다. API·테이블 구조·접수 제한 횟수·조회 및 삭제 권한은 유지한다. 운영 적용은 별도 배포 단계다.
