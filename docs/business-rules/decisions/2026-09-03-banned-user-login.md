# USER-002 정지 회원의 소셜 로그인 허용

- 결정일: 2026-09-03
- 상태: 확정
- 변경 전: 이용이 정지된 회원은 소셜 로그인을 할 수 없었다. 이미 발급된 인증이 만료되면 조회, 본인 게시물 삭제, 회원 탈퇴처럼 정지 회원에게 허용된 기능도 사용할 수 없었다.
- 변경 후: 탈퇴하지 않은 정지 회원은 소셜 로그인으로 인증할 수 있다. 회원가입과 게시물 작성, 사인 교체, 좋아요 등록 같은 쓰기 제한은 유지한다. 정지 상태로 탈퇴한 회원의 로그인·재가입 차단도 유지한다.
- 변경 이유: 정지된 회원도 자신의 계정을 삭제할 권리가 있다. 로그인을 막으면 인증이 만료된 정지 회원은 탈퇴를 요청할 방법이 없으므로, 탈퇴와 그에 필요한 인증까지는 허용한다.
- 영향 범위: 소셜 로그인(Google·Kakao, 이후 추가된 Apple 포함)과 정지 회원의 조회·본인 데이터 정리·탈퇴. 정지 회원은 로그인에 성공하지만 쓰기 요청은 거절된다. 최초 규칙 정리(#320)에 이 결정이 반영되지 않아 USER-002 문구는 #393에서 정정했다.
- 관련 규칙: USER-002, USER-003, USER-005
- 관련 이슈·PR: #260, #261, #393
