# USER-007 작가 신청

- 결정일: 2026-11-11, PR 리뷰 반영 2026-11-12
- 상태: 확정
- 변경 전: 첫 설계는 신청에 원작 확약을 요구했고 이미 작가인 회원도 최초 동의를 기록할 수 있었다.
- 변경 후: MVP에서 원작 확약 절차를 제외한다. 이용 가능한 일반 회원은 신청 시점에 공개 중인 본인 게시물의 받은 좋아요가 합계 100개 이상이면 작가가 된다. 이미 작가인 회원의 신청은 거절한다. 관리자 회수로 일반 회원이 된 경우 같은 기준으로 다시 신청할 수 있다.
- 변경 이유: 회원이 받은 반응으로 직접 작가 자격을 얻을 수 있게 하고, MVP에서는 신청 절차를 줄인다. 자격 조회 이후에 공개 범위와 좋아요 수가 달라질 수 있으므로 실제 신청에서도 같은 조건을 확인한다.
- 영향 범위: 사용자 v1 내 정보·자격 조회, 작가 신청, 이용 정지. 앱은 요청 본문 없이 작가 신청을 보내고 반환된 역할을 사용한다.
