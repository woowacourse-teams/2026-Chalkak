# USER-007 작가 신청과 원작 확약 동의

- 결정일: 2026-11-11
- 상태: 확정
- 변경 전: 회원이 작가 역할을 얻거나 원작 확약에 동의하는 절차가 없었다.
- 변경 후: 일반 회원은 신청 시점에 공개 중인 본인 게시물의 좋아요가 합계 100개 이상이고 원작 확약에 동의하면 작가가 된다. 작가 역할을 이미 받은 회원은 좋아요 조건 없이 동의만 할 수 있다. 반복 동의 요청은 최초 시각을 보존한다.
- 변경 이유: 회원이 받은 반응으로 직접 작가 자격을 얻을 수 있도록 하고, 역할 부여 경로와 별개로 실제 이용자의 확약을 기록한다. 자격 조회 이후에 공개 범위와 좋아요 수가 달라질 수 있으므로 실제 신청에서도 같은 조건을 확인한다.
- 영향 범위: 사용자 v1 내 정보·자격 조회, 작가 신청, 이용 정지. 앱은 원작 확약 동의를 받은 후 신청하고 반환된 역할과 동의 여부를 사용한다.
