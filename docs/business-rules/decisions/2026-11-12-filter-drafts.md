# 필터 초안과 소개 사진

- 결정일: 2026-11-12
- 상태: 확정
- 변경 전: 사진 업로드 ID는 게시물에 연결하는 용도로 사용했다. 작가가 필터 초안을 만들고 관리하는 API가 없었다.
- 변경 후: 이용 가능한 작가는 본인의 필터 초안을 생성·수정·삭제할 수 있다. 소개 사진에는 기존 게시물 사진 업로드를 재사용하고, 각 업로드 ID는 게시물이나 필터 소개 사진에 한 번만 연결한다. 본인은 초안과 비공개 필터를 조회할 수 있으며, 다른 로그인 회원에게는 공개 필터를 표시한다.
- 변경 이유: 작가가 공개 전에 소개 정보를 단계적으로 준비할 수 있게 한다. 기존 업로드와 이미지 처리 흐름을 재사용하고, 같은 사진 업로드가 여러 곳에 연결되는 것을 막는다.
- 영향 범위: 필터 초안 작성·삭제 화면, 작가별 필터 목록과 상세 화면, 게시물 업로드 ID를 소개 사진으로 연결하는 요청
- 관련 규칙: FILTER-001, FILTER-002, FILTER-003, POST-004
