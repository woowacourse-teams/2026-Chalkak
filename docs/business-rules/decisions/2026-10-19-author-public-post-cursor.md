# POST-012 작성자 공개 사진의 날짜 커서 이어보기

이 문서는 PR #700의 초기 커서안에 대한 변경 이력이다. 리뷰 후 사용자가 페이지 번호 방식과 조회 중 중복·누락 가능성 허용을 선택하여 대체되었다. 아래는 초기 결정이며 현재 정책은 POST-012와 페이지 번호 결정 기록을 따른다.

- 결정일: 2026-10-19
- 상태: 대체됨 — [페이지 번호 이어보기 결정](2026-10-19-author-public-post-pagination.md)을 따른다.
- 변경 전: 작성자의 최근 공개 사진만 기본 20개, 요청 시 1~100개 조회하며 과거 구간을 이어 받는 방법이 없었다.
- 변경 후: 동일한 API에 선택적 날짜 `cursor`를 추가한다. 커서보다 과거의 공개 사진을 조회하며 응답에 `hasNext`·`nextCursor`를 추가한다. 다음 묶음이 있으면 마지막 반환 사진의 주제 날짜를 `nextCursor`로 제공하고, 마지막 묶음과 빈 목록은 `false`·`null`로 종료한다. 기본 20개·허용 범위 1~100개는 유지한다.
- 변경 이유: 사용자는 오래된 사진까지 순서대로 탐색하길 원한다. 날짜별 활성 주제 하나와 작성자별 공개 사진 하나라는 제약을 이용하면 제출 시각이나 게시물 존재 여부에 의존하지 않고 주제 날짜 경계로 이어볼 수 있다.
- 조회 중 변경: 이미 지난 구간에 뒤늦게 공개된 사진은 새로고침·재진입 때 반영하고, 미조회 구간은 요청 시점의 승인·삭제 조건을 적용한다. 커서 게시물 삭제가 조회를 막지 않는다.
- 영향 범위: `GET /api/v1/users/{userId}/posts`의 선택 입력과 응답 필드 추가, 관련 테스트·Swagger·연동 안내. 기존 사진·주제 필드와 접근 정책은 유지한다. 피드·상세·본인 캘린더에는 영향이 없다.
- 관련 규칙: POST-007, POST-012, TOPIC-002
- 관련 이슈: [상위 #679](https://github.com/woowacourse-teams/2026-Chalkak/issues/679), [선행 #680](https://github.com/woowacourse-teams/2026-Chalkak/issues/680), [이번 #681](https://github.com/woowacourse-teams/2026-Chalkak/issues/681)

`cursor`는 날짜만 포함하며 잘못된 형식·빈 값·존재하지 않는 날짜는 400으로 거절한다. 별도의 목록 스냅샷을 고정하지 않으므로 조회 중 미조회 구간의 공개 상태 변화는 반영된다. 피드·상세의 `authorId` 제공은 #682에서 구현한다.
