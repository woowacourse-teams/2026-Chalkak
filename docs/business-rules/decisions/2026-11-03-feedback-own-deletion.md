# FEEDBACK-003 본인 문의 삭제

- 결정일: 2026-11-03
- 상태: 확정
- 변경 전: 본인 문의 목록·상세는 조회할 수 있었지만 사용자가 삭제할 수 없었다.
- 변경 후: 정상·정지 회원은 본인 문의를 소프트 딜리트하고 `204`를 받는다. 원문·작성자·접수 시각은 보존하고 본인 목록·상세에서는 제외한다. 같은 문의를 다시 삭제해도 성공하며 최초 삭제 시각은 유지한다. 타인·없는 문의는 같은 `404 / BUSINESS_ERROR`로 거절한다. 탈퇴·비로그인은 차단한다.
- 변경 이유: 승인한 사용자 삭제 정책을 구현하고, 삭제로 문의 접수 제한을 우회하지 못하게 한다. 반복 요청은 기존 게시물 삭제처럼 처리하며, 동시 요청은 문의 행 잠금으로 직렬화한다.
- 영향 범위: `DELETE /api/v1/feedbacks/{feedbackId}` 추가. 기존 `deleted_at`을 사용하고 새 컬럼을 추가하지 않는다. 삭제해도 최근 접수 횟수는 유지한다. 답변 전·후 삭제 허용 정책 중 답변·알림 연동은 #905 이후 구현하며 이번 단위에는 미존재 답변 컬럼·알림 기능을 추가하지 않는다.
