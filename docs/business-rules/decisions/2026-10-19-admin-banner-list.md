# BANNER-004 관리자가 배너를 최신순으로 조회한다

- 결정일: 2026-10-19
- 상태: 확정
- 변경 전: 배너 등록만 제공하고 목록 조회는 제공하지 않았다.
- 변경 후: 관리자 전용 목록 API를 제공한다. 등록 시각·ID 내림차순, 1부터 시작하는 페이지, 기본 크기 20·최대 100과 다음 페이지 존재 여부를 사용한다. 목록 항목은 등록 응답과 같은 정보를 반환한다. 빈 목록과 범위 밖 페이지도 200으로 응답한다.
- 변경 이유: 관리자가 등록된 배너를 확인하도록 하며 기존 관리자 목록의 페이지 계약을 따른다. 상세 조회 API 없이 목록의 정보로 관리한다.
- 영향 범위: 관리자 목록 조회 추가이며 기존 등록 계약은 유지한다. 앱 공개 조회·삭제는 후속 이슈다.
