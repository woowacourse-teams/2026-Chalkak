# NOTIFICATION-006 회원별 푸시 수신 설정 조회

- 결정일: 2026-09-30 (기존 알림 인터뷰 합의의 조회 API 구현·문서 반영일)
- 상태: 확정
- 변경 전: 회원 계정에 두 푸시 수신 설정을 저장하지만 앱에서 이를 조회하는 API는 제공하지 않는다.
- 변경 후: 인증된 회원의 주제·승인·반려 푸시 수신 설정을 두 불리언 필드로 조회하는 API를 제공한다. 초기 설정은 두 항목 모두 켜짐이며 기기에 관계없이 같은 회원 계정의 설정을 조회한다.
- 변경 이유: 기존 알림 인터뷰에서 합의한 사용자별 수신 설정을 앱의 설정 화면에 표시한다. JWT의 회원 ID로 조회 대상을 정해 다른 회원의 설정을 노출하지 않는다.
- 영향 범위: 앱은 `GET /api/v1/notification-settings`의 `topicPushEnabled`와 `moderationPushEnabled`를 사용한다. 로그인 ID 없는 기존 회원 JWT도 사용할 수 있다. 정지 회원은 조회할 수 있고 탈퇴 회원은 조회할 수 없다. 반환값으로 운영체제의 알림 권한이나 실제 수신 여부를 판단하지 않는다. 수신 설정 수정 API와 실제 푸시 발송은 별도 구현 단위다.
