# NOTIFICATION-006 회원별 푸시 수신 설정 조회·수정

- 결정일: 2026-09-30 (조회 API 구현 및 부분 수정 방식 합의)
- 상태: 확정
- 변경 전: 회원 계정에 두 푸시 수신 설정을 저장하고 조회하는 API를 제공하지만 앱에서 수정하는 API는 제공하지 않는다.
- 변경 후: 인증된 회원은 주제·승인·반려 푸시 설정을 조회하고 값이 전달된 항목만 수정한다. 생략 또는 null은 기존 값을 유지하며 두 항목 모두 값이 없으면 400으로 거부한다. 초기 값은 모두 켜짐이고 설정은 회원 계정 단위다.
- 변경 이유: 스위치 하나를 바꿀 때 두 값을 모두 보내면 다른 기기에서 변경한 설정을 오래된 값으로 덮어쓸 수 있다. 사용자가 A 방식의 부분 수정과 null 처리·빈 요청 거부를 승인했다. 회원 ID는 JWT에서 식별하고 요청으로 받지 않는다.
- 영향 범위: 앱은 GET·PATCH `/api/v1/notification-settings`에서 `topicPushEnabled`와 `moderationPushEnabled`를 사용한다. PATCH는 변경할 항목만 보내고 본문 없는 204를 성공으로 처리한다. 로그인 ID 없는 기존 JWT와 정지 회원도 조회·수정할 수 있지만 탈퇴 회원은 거부한다. 설정은 운영체제 알림 권한이나 실제 수신 성공을 뜻하지 않으며 알림함에는 영향을 주지 않는다. 실제 푸시 발송은 별도 구현 단위다.
