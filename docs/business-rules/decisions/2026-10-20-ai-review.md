# AIREVIEW-001~006 AI 리뷰 요청·조회 도입

- 결정일: 2026-10-20
- 상태: 확정
- 변경 전: 관리자가 AI 프롬프트를 미리보기로 실행하고 버전으로 저장할 수 있었지만, 회원이 자기 사진의 AI 리뷰를 요청하거나 볼 방법이 없었다.
- 변경 후: 작성자는 공개된 본인 게시물에 AI 리뷰를 한 번 요청하고 결과를 조회한다([AIREVIEW-001](../rules/ai-review.md#aireview-001-요청-자격)~[006](../rules/ai-review.md#aireview-006-개인정보)). 요청은 접수만 하고 서버가 DB 대기열에서 비동기로 처리하며, 앱은 조회 API를 3초 간격으로 확인한다. 요청 시점의 용도별 최신 프롬프트 버전을 쓰고, 쓸 수 있는 버전이 없으면 새 요청을 거절한다. 실패는 임시로 최종이며 재요청·자동 재시도는 없다. 이용이 정지된 회원은 요청할 수 없고 조회할 수 있다([USER-002](../rules/user.md#user-002-이용-정지)). 관리자 조회는 제공하지 않는다.
- 변경 이유:
  - 처리 방식: OpenAI 호출은 수십 초가 걸려 요청 안에서 기다리지 않고 DB 대기열에 접수한 뒤 별도 처리 흐름이 가져가 처리한다. 별도 큐 인프라 없이 요청 내역과 결과를 한 곳에 남길 수 있고, 서버가 멈춰도 이어서 처리한다. 동시에 호출하는 수는 OpenAI의 분당 요청·토큰 한도를 지키려고 제한한다.
  - 프롬프트 버전: 관리자가 확인한 최신 버전을 곧바로 사용자에게 내보내려고 활성 버전 대신 용도별 최신 버전을 쓴다([ADMIN-011](../rules/admin.md#admin-011-ai-프롬프트-버전)). 서버가 해석할 수 없는 버전으로 결과를 만들지 않도록 이전 버전으로 대신하지 않는다.
  - 실패는 최종: 재요청과 자동 재시도는 정책을 따로 정해야 해 [#690](https://github.com/woowacourse-teams/2026-Chalkak/issues/690)으로 미룬다. 그래서 #689의 실패 최종 정책은 임시이고, #690에서 AIREVIEW-002를 갱신한다.
  - 공개 범위와 횟수: 게시물당 한 번이며 타인에게는 리뷰 존재 여부도 알리지 않아 404로 응답한다. 일일 한도는 두지 않는다.
  - 개인정보: OpenAI 국외 처리는 회원가입의 필수 약관 동의로 갈음한다. 앱 첫 사용 안내는 두지 않는다. 사진 주소와 주제 제목만 보내고 회원 식별자는 보내지 않으며 OpenAI에는 저장하지 않도록 요청한다.
- 영향 범위: 회원 API 두 개(`POST`·`GET /api/v1/posts/{postId}/ai-review`)와 AI 리뷰 테이블, 처리 워커. 앱은 AI 리뷰 요청·조회 화면이 필요하다([앱 연동 안내](../guides/ai-review.md)). 운영 확인이 필요하다.
  - 배포 전 prod의 `ai_prompt_versions` 행 수가 0인지 확인한다. 한 건이라도 있으면 배포 즉시 그 버전으로 기능이 켜진다.
  - 사용자 공개(prod 프롬프트 버전 생성)는 #690 병합 이후에 한다. 그전까지는 버전을 만들지 않아 기능을 꺼 둔다.
  - 명시적 비활성화([#701](https://github.com/woowacourse-teams/2026-Chalkak/issues/701)) 전에 기능을 끄려면 허용 모델 목록에서 모델을 빼고 재배포한다. 대기 중인 요청도 호출 직전에 다시 확인해 호출 없이 실패로 끝낸다. OpenAI 예산 한도도 함께 둔다.
  - 배포 중에는 처리 중이던 건이 임대 시간(2분) 뒤에 이어서 처리되어 최대 약 3분 지연될 수 있다.
