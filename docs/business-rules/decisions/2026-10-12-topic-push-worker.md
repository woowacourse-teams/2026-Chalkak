# NOTIFICATION-010 주제 메시지의 공통 Worker 처리

- 결정일: 2026-10-12
- 상태: 확정
- 변경 전: 공통 Worker는 승인·반려의 알림함 ID와 DB 알림을 기준으로 발송 조건을 검증했다. 알림함에 저장하지 않는 주제 메시지는 처리할 수 없었다.
- 변경 후: 주제 종류·관련 대상은 `TOPIC`으로 구분하고 알림함 ID 없이 처리한다. 기존 로그인·기기 검증과 FCM 결과·SQS 완료 처리를 재사용하면서, 주제만 정상 회원·주제 수신 설정·KST 오늘 주제의 일치 여부를 확인한다. 현재 기기를 조회하므로 예정 시각 이후 등록한 기기도 포함한다. 제목은 `오늘의 주제`, 본문은 주제명으로 구성한다. 앱은 원래 주제 ID로 날짜를 고정하지 않고 클릭한 날의 오늘 주제를 조회한다.
- 변경 이유: 주제를 알림함·Outbox에 저장하지 않는 합의와 기존 발송 흐름을 함께 유지한다. 승인·반려의 정지 회원 허용 정책을 주제에 적용하지 않고, 독립된 두 수신 설정을 각 종류에 맞게 판단한다. 앱은 없는 알림함 ID로 상세·읽음 API를 호출하지 않아야 한다.
- 영향 범위: 주제 SQS 메시지, 공통 Worker와 FCM 데이터, Android·iOS 표시·클릭 계약. 승인·반려의 기존 메시지 필드와 REST 응답은 유지한다. 새 enum 값은 주제 푸시용이며 주제 알림함 행을 생성하지 않는다.
- 관련 규칙: NOTIFICATION-005, NOTIFICATION-006, NOTIFICATION-008, NOTIFICATION-009, NOTIFICATION-010
- 관련 이슈·PR: [#572](https://github.com/woowacourse-teams/2026-Chalkak/issues/572). PR은 아직 등록하지 않았다.

이 기록은 기존 합의의 구현 반영이다. 첫 커밋은 SQS 이후의 처리와 계약을 완성하며, 정시 직접 발행·설정 적용 시점은 다음 커밋에서 연결한다. 실제 AWS·Firebase·기기 연동과 서버 배포는 아직 확인하지 않았다. 수락은 기기 수신을 뜻하지 않는다.
