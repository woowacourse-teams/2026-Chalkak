# POST-012 작성자 공개 사진의 페이지 번호 이어보기

- 결정일: 2026-10-19
- 상태: 확정
- 변경 전: PR #700 초기안은 마지막 사진의 주제 날짜를 `cursor`로 전달해 과거 구간을 조회하고 `hasNext`·`nextCursor`를 응답했다. 날짜 경계로 지나온 구간의 승인·삭제에 따른 페이지 위치 이동을 피하려 했다.
- 변경 후: 기존 목록 API와 동일하게 `page`(기본 1, 최소 1)·`pageSize`(기본 20, 1~100)를 요청하고 `currentPage`·`pageSize`·`hasNext`·`posts`를 응답한다. `cursor`·`nextCursor`는 제공하지 않는다. 마지막 페이지와 빈 목록은 `hasNext=false`이며 범위를 벗어난 페이지도 요청한 페이지 번호·크기와 빈 목록을 반환한다.
- 변경 이유: 리뷰에서 피드·알림·공지·관리자 목록과 다른 이어보기 방식의 앱 연동 비용과 일관성 문제가 제기됐다. 사용자는 페이지 번호 방식으로 맞추고 조회 중 승인·삭제로 인한 중복·누락 가능성을 허용하기로 선택했다. 정렬은 주제 날짜 최신순을 유지한다.
- 조회 중 변경: 각 요청 시점의 공개 사진을 현재 정렬 순서로 조회한다. 승인된 사진이 앞에 추가되면 이미 본 사진을 다음 페이지에서 다시 볼 수 있고, 앞쪽 사진이 삭제되면 아직 보지 않은 사진을 건너뛸 수 있다. 목록 전체의 고정된 스냅샷이나 중복·누락 방지는 제공하지 않으며 새로고침·재진입은 1페이지부터 조회한다.
- 영향 범위: `GET /api/v1/users/{userId}/posts`의 미병합 이어보기 계약, 관련 테스트·Swagger·규칙·연동 안내. 병합된 #680의 기본 최근 사진 조회와 사진 항목·공개 조건·인증·작성자 없음 응답은 유지한다. 기존 피드·알림·관리자 API를 변경하는 작업은 아니다.
- 관련 규칙: POST-007, POST-012
- 관련 이슈·PR: [상위 #679](https://github.com/woowacourse-teams/2026-Chalkak/issues/679), [이번 #681](https://github.com/woowacourse-teams/2026-Chalkak/issues/681), [PR #700 리뷰](https://github.com/woowacourse-teams/2026-Chalkak/pull/700#discussion_r4312961251)
- 이전 결정: [날짜 커서 이어보기 초기안](2026-10-19-author-public-post-cursor.md)

이번 선택은 아직 병합되지 않은 PR의 계약 변경이다. 커서 API가 운영이나 지원 중인 클라이언트에 배포된 것으로 전제하지 않는다. 공개 사진이 없는 정상 회원과 없는·탈퇴한 작성자의 구분, 본인 조회에도 공개 승인 사진만 보여주는 정책, 후속 #682의 `authorId` 제공 범위는 그대로 유지한다.
