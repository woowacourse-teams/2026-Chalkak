# NOTIFICATION-005 로그인별 푸시 기기 등록

- 결정일: 2026-09-30 (기존 알림 인터뷰 합의의 구현·문서 반영일)
- 상태: 확정
- 변경 전: 알림함 조회·읽음 계약만 제공하며 앱 기기 등록 API는 제공하지 않는다.
- 변경 후: 현재 로그인에 FCM 토큰을 등록·갱신하는 API를 제공한다. 로그인 하나에 등록 하나를 유지하며 같은 토큰의 연결은 새 로그인으로 이동한다. 최초 등록 시각은 반복 등록과 토큰 교체에도 유지한다.
- 변경 이유: 기존 알림 인터뷰에서 합의한 로그인별 기기 연결과 서버·앱 계약을 구현한다. 같은 앱이 재로그인해도 이전 계정의 연결로 푸시가 전달되지 않도록 하며, 이후 발송 단계에서 등록 시각으로 대상 기기를 판단할 수 있게 한다.
- 영향 범위: 앱은 로그인 후 FCM 토큰이 준비되었을 때 등록하고, 토큰 변경 또는 인증된 앱 재시작 시 갱신한다. 로그인 ID가 없는 이전 액세스 토큰은 기존 API를 계속 사용할 수 있고, 기기 등록 전에 기존 리프레시 토큰으로 자동 갱신하면 로그인 ID가 포함된 JWT를 받을 수 있다. 갱신된 두 토큰을 저장한 뒤 등록하며 인증 갱신이 거절될 때 재로그인한다. 기기 등록 실패만으로 로그인 상태를 해제하지 않는다. 정지 회원은 등록할 수 있고 탈퇴 회원은 등록할 수 없다. 실제 발송과 로그아웃·탈퇴 시 기기 비활성화 연동은 별도 구현 단위다.
