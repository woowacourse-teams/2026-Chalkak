# FEEDBACK-001 회원별 문의 접수 제한

- 결정일: 2026-11-03
- 상태: 확정
- 변경 전: 정상·정지 회원의 피드백 제출 간격과 횟수를 제한하지 않았다.
- 변경 후: 정상·정지 회원 모두 회원별 1분에 1건, 최근 24시간에 최대 5건을 접수한다. 성공 접수만 집계하고 실패 요청은 저장하지 않는다. 정확한 시간 경계에는 접수를 허용하며 중첩 제한은 모두 해제되는 시각을 안내한다. 고객센터 접수 Slack 알림과 관리자 개별 차단·해제는 제공하지 않는다.
- 변경 이유: 정지 회원의 문의 통로를 유지하면서 반복 접수로 인한 관리자 부담을 줄인다. 별도의 회원별 차단 관리보다 동일한 자동 제한을 먼저 적용하기로 합의했다.
- 영향 범위: 기존 `POST /api/v1/feedbacks`의 성공 요청·응답과 인증 범위는 유지한다. 제한 초과는 기존 `400 / BUSINESS_ERROR`와 `errorCode`·`message` 형식을 사용하며, 메시지에 재접수 가능한 UTC 시각을 제공한다. 앱은 입력 오류와 같이 서버 안내를 표시한다. 기존 게시물 검수 알림은 변경하지 않는다.
- 관련 규칙: FEEDBACK-001, FEEDBACK-002, USER-002
- 관련 이슈·PR: [#903](https://github.com/woowacourse-teams/2026-Chalkak/issues/903). PR 미등록·운영 미배포.

문의 조회·삭제, 기존 데이터의 고객센터 조회 제외, 관리자 답변과 사용자 답변 알림은 승인한 후속 커밋·이슈에서 구현한다. 이번 변경을 그 기능들의 구현 완료로 해석하지 않는다.
