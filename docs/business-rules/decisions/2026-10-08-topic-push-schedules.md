# NOTIFICATION-009 주제 푸시 설정의 변경 적용 시점

- 결정일: 2026-10-08
- 상태: 확정
- 변경 전: 관리자 다중 KST 발송 시각은 합의했지만 설정 변경의 적용 시점은 정하지 않았다. #493에는 이전 최대 3회 SQS 수신 설명도 남아 있었다.
- 변경 후: 설정 생성·시각 수정은 변경 이후 도래하는 시각부터 적용하고, 지난 시각은 소급 실행하지 않는다. 설정 삭제는 미실행 발송부터 취소하며 이미 SQS에 발행한 작업은 계속 처리한다. SQS 최대 수신은 기존 최신 합의인 최초 수신 포함 10회로 맞춘다.
- 변경 이유: 관리자 설정 변경 때문에 지난 발송을 갑자기 실행하거나 이미 발행한 작업을 소급 취소하지 않도록 적용 기준을 명확히 한다. 별도 사용자별 작업·회차 기록과 DB 복구를 만들지 않는 기존 선택을 유지한다. 발송 시각만 저장하는 설정은 삭제·재생성이 간단하므로, 사용자 요청에 따라 활성 여부 필드와 일시 중지 기능을 제거한다.
- 영향 범위: 관리자 설정 CRUD, KST 정시 실행, 주제 메시지 발행, Worker의 최신 조건 검증, API·앱 연동 안내. 현재 생성 API만 구현하며 실제 실행 동작은 #493 후속 단위에서 검증한다.
- 관련 규칙: NOTIFICATION-009, ADMIN-001. SQS 처리의 기존 시간·횟수 기준은 NOTIFICATION-008과 동일하다.
- 관련 이슈·PR: [#493](https://github.com/woowacourse-teams/2026-Chalkak/issues/493). 이 구현의 PR은 아직 등록하지 않았다.

## 합의한 적용 예시

KST 14:00에 15:00 설정을 추가하면 오늘 15:00부터, 13:00 설정을 추가하면 내일 13:00부터 실행한다. 15:00을 13:00으로 수정해도 오늘 소급 발송하지 않는다. 아직 실행하지 않은 15:00 설정을 삭제하면 오늘 발송부터 취소한다. 이미 SQS에 발행한 작업은 설정 변경만으로 취소하지 않고 기존 최신 조건과 원래 기한을 따른다.
